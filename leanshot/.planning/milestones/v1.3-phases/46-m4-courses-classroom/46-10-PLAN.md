<objective>
Ship the public `/verify/<cert_id>?t=<hmac_token>` route — a fully no-auth SPA branch that lets anyone with a cert URL verify its authenticity. The route bypasses the TabId pattern entirely (it's not a tab), gates entry via `window.location.pathname.startsWith('/verify/')` in App.tsx, fetches the cert row from `public.certificates` (RLS allows anon SELECT when verification_token is non-null per Plan 46-01), validates the HMAC via the browser-side `verifyCertToken` helper (Plan 46-03), and renders a proof card or a "Certificate not found" state.

Purpose: COURSE-04's verification leg. Without this route, the verification URL printed on the cert PDF is dead. Public access (no auth) is intentional — anyone presented with a cert PDF can verify it. Security comes from HMAC, not from auth.

The `CERT_VERIFICATION_SECRET` is NEVER exposed to the browser. How does the browser verify the HMAC without the secret? **It doesn't compute — it COMPARES.** The browser does NOT need the secret. Instead, the browser fetches `certificates.verification_token` from the DB (RLS allows anon SELECT) and compares it to the `t=` URL param via constant-time string equality. The HMAC was minted server-side; the DB holds the canonical token; the browser only needs to confirm "URL token == DB token". `verifyCertToken` in Plan 46-03 is the constant-time string compare wrapper — it does NOT require the secret to validate; only mint requires the secret. **Update Plan 46-03's verifyCertToken to support this comparison-only mode** OR add a thin `compareCertToken(urlToken, dbToken)` helper. Decision below.

Output: 1 new component + 2 modified files (App.tsx + index.html).
</objective>

    ```ts
    /**
     * Constant-time string compare for verification token from URL vs DB-stored canonical token.
     * Used by the public /verify/<cert_id> route which has no access to CERT_VERIFICATION_SECRET.
     * The HMAC was minted by the Edge Fn (Plan 46-07) and stored in certificates.verification_token.
     * The browser simply confirms "URL ?t= param == DB column value".
     */
    export function compareCertToken(urlToken: string, dbToken: string): boolean {
      if (!urlToken || !dbToken) return false;
      if (urlToken.length !== dbToken.length) return false;
      let diff = 0;
      for (let i = 0; i < urlToken.length; i++) {
        diff |= urlToken.charCodeAt(i) ^ dbToken.charCodeAt(i);
      }
      return diff === 0;
    }
    ```
