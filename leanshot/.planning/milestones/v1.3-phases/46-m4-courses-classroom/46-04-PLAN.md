<objective>
Ship the `mux-sign-playback` Edge Fn that mints time-limited RS256 JWT tokens for Mux playback + thumbnail URLs. The Fn (a) authenticates the user via bearer JWT, (b) checks tier_effective.has_active (with free-preview bypass), (c) signs both video + thumbnail tokens via `mux.jwt.signPlaybackId` with EXPLICITLY-passed keyId/keySecret options (decoupling from the SDK's `MUX_SIGNING_KEY`/`MUX_PRIVATE_KEY` env-var defaults per RESEARCH Pitfall 4 + critical correction 3), (d) returns both tokens to the client.

Purpose: Without signed JWTs, `playback_policies: ['signed']` (set by Plan 46-05 on course-lesson uploads) would block all playback. This Fn is the only gate between an authenticated learner and the encoded video.

Output: 1 new Edge Fn + deno.json + Deno test file.
</objective>
