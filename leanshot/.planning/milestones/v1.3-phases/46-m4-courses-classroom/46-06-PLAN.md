<objective>
Ship the `lesson-progress-beacon` Edge Fn that handles tab-close progress saves from `navigator.sendBeacon`. The fn's single responsibility: accept a text/plain JSON body containing lesson_id + last_position_seconds + max_position_reached_seconds + access_token, validate the access_token, and invoke `update_lesson_position` SECDEF RPC (which handles the GREATEST UPSERT).

Purpose: Without this Fn, the user's final scroll position before tab-close is lost. The Mux Player onTimeUpdate listener (Plan 46-08) has at most a 15-second debounce window; tab-close interrupts that, so sendBeacon is the catch.

Critical correctness requirement (per CONTEXT.md correction 8 + RESEARCH Pitfall 3): `req.json()` will throw on a sendBeacon request because the content-type is `text/plain;charset=UTF-8`, not `application/json`. The fn MUST `req.text()` then `JSON.parse()`.

Output: 1 new Edge Fn + deno.json + Deno test file.
</objective>

        ```ts
            auth: { autoRefreshToken: false, persistSession: false },

          p_lesson_id: lessonId,
          p_last_position_seconds: Math.max(0, Math.round(lastPos)),
          p_max_position_reached_seconds: Math.max(0, Math.round(maxPos)),
        });
        ```
