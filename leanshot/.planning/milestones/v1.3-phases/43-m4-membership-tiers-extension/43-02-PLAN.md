|----------|-------------|
| authenticated user → grandfathered_prices (read) | Admin-only via RLS predicate; denial-by-default for non-admin authenticated |
| authenticated user → grandfathered_price_* RPCs | SECDEF function bypasses RLS but explicitly re-checks `is_admin_at_least('admin')` inside; service-role callers without auth.uid() rejected with '28000' |
| any caller → grandfathered_prices direct write | DENIED — no INSERT/UPDATE/DELETE RLS policy + RPCs are the only path |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-43-02-01 | Elevation of Privilege | non-admin user calls grandfathered_price_create | mitigate | RPC body re-checks `is_admin_at_least('admin')` and raises '42501' / 'forbidden'; SECDEF cannot be bypassed by the authenticated role |
| T-43-02-02 | Tampering | malformed stripe_price_id smuggled in (e.g., SQL-injection-shaped) | mitigate | Regex validation `^price_[A-Za-z0-9]+$` in RPC body; parameterized INSERT (plpgsql binds args); raises '22023' / 'invalid_stripe_price_id' |
