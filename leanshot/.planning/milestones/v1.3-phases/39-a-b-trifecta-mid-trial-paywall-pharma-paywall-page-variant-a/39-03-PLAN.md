variant-resolver request/response contract (consumed by PaywallGate, PaywallModal, OnboardingFlowPaywall, PharmaContentBlock in Wave 3, and by page-render in Plan 39-09):

POST /functions/v1/variant-resolver
  Headers: Authorization: Bearer <user-jwt>, Content-Type: application/json
  Body: { surface: 'paywall' | 'page' | 'pharma', page_id?: string, block_id?: string }
  Response 200: { variant_id: string, config: Record<string, unknown> }
  Response 401: { error: 'unauthenticated' }
  Response 400: { error: 'invalid_body' }
  Response 503: { error: 'vendor_unconfigured', service: 'posthog' }

Resolution order (D-10 cohort wins over UTM):
  1. If existing user_experiments row for (uid, surface) — return its variant_id
  2. If surface='pharma' AND (region in {WA,CT} OR lt_pharma_blocked cookie OR profile.state_of_residence in {WA,CT}) — return {variant_id:'control', config:{}}
  3. Call adminClient.rpc('resolve_cohort_for_user', { uid }) -> cohort_id (or null)
  4. If cohort_id: SELECT variant_config WHERE cohort_id=$1 AND surface=$2 AND archived_at IS NULL
  5. Else: SELECT utm_variant_map WHERE utm_source = cookie lt_utm_source (default if absent) -> variant_id
  6. UPSERT user_experiments (user_id, surface, variant_id, cohort_id, utm_variant_id)
  7. captureServer({ userId: uid, event: '$feature_flag_called', properties: { surface, variant_id, $feature_flag: `phase39_${surface}` } })
  8. SELECT variant_config.config WHERE id = variant_id -> return

Kill-scan SQL functions (in migration 20270714000015):
  public.p39_variant_42day_archive_scan() returns void
    - UPDATE page_variants SET warned_at = now() WHERE warned_at IS NULL AND archived_at IS NULL AND created_at <= now() - interval '35 days' AND created_at > now() - interval '42 days'
    - UPDATE page_variants SET archived_at = now(), traffic_to_control = true WHERE archived_at IS NULL AND created_at <= now() - interval '42 days'
    - net.http_post slack-alert-experiments with kind='archive_42d' or 'archive_warn_35d' if any row touched

  public.p39_refund_rate_kill_scan() returns void
    - Aggregate refunds per variant over trailing 7d and 30d (CONTROL baseline = 30d mean refund rate on variant_id IS NULL or variant_id = control)
    - Per non-control variant: if 7d_refund_rate > 2 * baseline, UPDATE variant_config SET archived_at = now() WHERE id = <variant>, fire slack-alert-experiments kind='refund_kill'
    - Idempotent: if archived_at IS NOT NULL, skip
    - MUST NOT call any SECDEF RPC that references auth.uid() per [[feedback_rpc_auth_uid_vs_service_role_mismatch]]; this function operates entirely in service-role context with direct table reads

  public.p39_pharma_nps_kill_scan() returns void
    - Per pharma variant: compute NPS for variant assignees over the variant lifetime; compute prior 30d baseline NPS
    - If NPS dropped by >=5 points, kill (archive + slack)
    - Compute 1★ review rate for variant assignees in last 7d vs trailing 30d baseline
    - If 1★ rate > 2x baseline, kill (archive + slack)
    - Either trigger disables — OR semantics per D-03
