    **RPC 1: `send_org_patient_invite`**
    ```
    create or replace function public.send_org_patient_invite(
      p_org_id            uuid,
      p_patient_email     citext,
      p_consent_scope     jsonb,
      p_invite_token_hash text
    ) returns table(invite_id uuid, status text)
      language plpgsql security definer
      set search_path = pg_catalog, public, extensions
    as $$
    declare v_role public.org_member_role; v_invite_id uuid;
    begin
      -- Pattern S1: role re-check
      select role into v_role from public.org_members where org_id = p_org_id and user_id = auth.uid();
      if v_role is null or v_role <> 'admin' then
        raise exception 'admin role required' using errcode = '42501';
      end if;

      -- W-1 invariant: ALWAYS insert (no branch on auth.users existence)
      insert into public.org_patient_invites(org_id, patient_email, invite_token_hash, consent_scope, invited_by)
        values(p_org_id, p_patient_email, p_invite_token_hash, p_consent_scope, auth.uid())
        returning id into v_invite_id;

      -- Phase 24 audit invariant
      perform public.log_admin_action(
        p_action     => 'send_org_patient_invite',
        p_table_name => 'org_patient_invites',
        p_record_id  => v_invite_id,
        p_new_data   => jsonb_build_object('org_id', p_org_id, 'patient_email', p_patient_email)
      );

      return query select v_invite_id, 'sent'::text;
    end; $$;
    revoke all on function public.send_org_patient_invite(uuid, citext, jsonb, text) from public;
    grant execute on function public.send_org_patient_invite(uuid, citext, jsonb, text) to authenticated;
    ```
    Note: `_validate_consent_scope` runs via the BEFORE INSERT trigger added in Task 1 — no explicit `perform _validate_consent_scope` call needed here.

    **RPC 2: `accept_org_patient_invite_preview` (called by Edge Function before showing consent screen)**
    - Signature: `(p_invite_token_hash text) returns table(org_name text, org_logo_url text, scope_summary jsonb)`.
    - SECURITY DEFINER, search_path locked, language plpgsql, STABLE.
    - Body: SELECT invite + JOIN organizations + JOIN org_branding to get name/logo. WHERE invite_token_hash = p_invite_token_hash AND accepted_at IS NULL AND expires_at > now().
    - If no row: `raise exception 'invite not found' using errcode = 'P0002';` (Postgres "no_data_found"; Edge Function maps to 404 per anti-enumeration W-1 — return identical 404 for invalid OR expired).
    - `grant execute on function public.accept_org_patient_invite_preview(text) to anon, authenticated;` (anonymous because the patient may not be authenticated yet).
    - NO log_admin_action call (read-only).

    **RPC 3: `accept_org_patient_invite` (single-transaction commit)**
    - Signature: `(p_invite_token_hash text, p_patient_user_id uuid) returns table(org_id uuid, status text)`.
    - SECURITY DEFINER, search_path locked, VOLATILE.
    - Body in single transaction (entire function body IS one transaction in Postgres):
      a. SELECT invite row by token_hash where accepted_at IS NULL AND expires_at > now() INTO v_invite — raise 'invite not found' (P0002) if missing.
      b. UPDATE public.profiles SET primary_org_id = v_invite.org_id WHERE id = p_patient_user_id (per D-09 + D-08 step b).
      c. INSERT INTO public.org_consent_grants(org_id, patient_user_id, scope, granted_at, granted_via) VALUES (v_invite.org_id, p_patient_user_id, v_invite.consent_scope, now(), 'invite') RETURNING id INTO v_consent_grant_id.
      d. INSERT INTO public.org_patient_links(org_id, patient_user_id, linked_by, linked_at, consent_grant_id) VALUES (v_invite.org_id, p_patient_user_id, v_invite.invited_by, now(), v_consent_grant_id).
      e. UPDATE public.org_patient_invites SET accepted_at = now() WHERE id = v_invite.id.
      f. perform public.log_admin_action('accept_org_patient_invite', 'org_patient_invites', v_invite.id, jsonb_build_object('patient_user_id', p_patient_user_id, 'org_id', v_invite.org_id)).
      g. return query select v_invite.org_id, 'accepted'::text.
