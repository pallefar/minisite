  <action>
Implement modeled on `_shared/anthropic-summarize.ts`. Input: `{ ticket_id, message_id }` POST body. Auth: service-role Bearer (caller is helpdesk-inbound or admin).

**Pipeline (every step name MATTERS — out-of-order = audit defect):**

1. **Auth gate** — verify `Authorization: Bearer ${SUPABASE_SERVICE_ROLE_KEY}`; return 401 on mismatch.

2. **Input parse** — parse body, validate non-empty `ticket_id` + `message_id`; 400 on missing.

3. **Ticket lookup FIRST** — `admin.from('tickets').select('id, org_id, user_id, phi, status, assigned_to, subject').eq('id', ticket_id).single()`. 404 if missing. Read `ticket.phi` into local var.

4. **Message lookup** — fetch ticket_messages row. Skip-with-200 if `author_kind !== 'user'` (skip agent replies, system messages, ai_draft).

5. **resolveBaaScope(admin, ticket.user_id)** — scope is decided by the TICKET OWNER actor per D-01 (clinician → phi=true → BAA credential). Emits 'baa.scope.resolved' breadcrumb internally.

6. **assertBaaScope(scope, MODEL_ID)** — throws `BaaScopeError` if model not on allowlist for the scope. Catch → log `'baa-scope-mismatch'` code only (NEVER log message body) → return 403.

7. **addBreadcrumb({ category: 'anthropic.messages.create', level: 'info', data: { model_id, is_clinical, ticket_id }})** — fired immediately before the fetch call.

8. **fetch `${ANTHROPIC_API_BASE}/v1/messages`** — `Bearer ${scope.credential}`, model = MODEL_ID (hyphenated, e.g. `claude-sonnet-4-6`), `anthropic-version: 2023-06-01`. Body includes SYSTEM_PROMPT + a user message that contains the ticket subject + body. NO `/chat/completions` endpoint (per [[reference_anthropic_model_id_hyphenated_format]]).

9. **Refusal detection** — if Claude's text matches `/^I (cannot|can't|am unable to)\s+(provide|give|assist|help)/i`, store an empty `ticket_ai_suggestions` row with `sentiment_score=0`, no tags, null draft; return 200. Mirrors Phase 25 SC#1 refusal-corpus pattern.

10. **Zod parse** the Claude JSON output against the structured schema. On parse failure: store empty suggestion (audit trace), return 200.

11. **Routing resolution** — if `parsed.routing_suggestion` is set, look up `helpdesk_routing_rules WHERE org_id = ticket.org_id AND tag_name = parsed.routing_suggestion AND active = true ORDER BY priority DESC LIMIT 1`. If matched, capture `assign_to_user_id` + `confidence` (from the top tag).

12. **INSERT `ticket_ai_suggestions`** — all parsed fields + `model_id=MODEL_ID`, `is_clinical_scope=scope.isClinical`. Capture the inserted suggestion id.

13. **Auto-apply gate (D-06)** — if any tag has confidence ≥0.75 OR route confidence ≥0.75:
    a. `admin.rpc('apply_ai_suggestion', { p_suggestion_id: <id> })`
    b. Emit `helpdesk.ai.tagged` event (tags above threshold).
    c. If route applied, emit `helpdesk.ticket.assigned` + `helpdesk.ai.routed`.

14. **Sentiment alert (D-10)** — fire alert if `sentiment_score <= -0.6` OR aggregate (`count(ticket_ai_suggestions WHERE ticket_id=X AND sentiment_score<=-0.3) >= 3`). On alert: UPDATE `tickets SET sentiment_min_score=parsed.sentiment_score, sentiment_alert_fired_at=now()`; emit `helpdesk.sentiment_alert.fired` + `helpdesk.ai.sentiment_flagged`.

15. **Return** `{ ok: true, suggestion_id, applied, sentiment_alert }`.

**SYSTEM_PROMPT** (module constant, no PHI placeholders): instructs Claude to output STRICT JSON matching the Zod schema with a closed tag set `[billing, account, technical, bug, feature_request, kb_question, urgent_safety, integration, data_export, refund_request, account_deletion, escalation, other]`. The prompt explicitly says `draft_reply` is NEVER sent automatically (defense in depth — model is told not to use placeholders like `[name]`).

**cors.ts** — copy from `_shared/anthropic-summarize` peer / `clinic-invite/cors.ts` verbatim.

Forbidden:
- Do NOT log `msg.body`, `parsed.draft_reply`, or any field that could contain PHI. `console.warn` with `'short-code-only'` strings (no template literals over user content).
- Do NOT import or call `sendEmail` — draft replies are stored only.
- Do NOT use the dotted model id `claude-sonnet-4.6` — hyphenated only.
- Do NOT use `/chat/completions` — Anthropic-native is `/v1/messages`.
- Do NOT trust the caller's hint about phi — re-resolve via `resolveBaaScope` against `ticket.user_id` every time.
- Do NOT call `apply_ai_suggestion` if NO tag and NO route meets the 0.75 threshold (suggestion-only path per D-07).
