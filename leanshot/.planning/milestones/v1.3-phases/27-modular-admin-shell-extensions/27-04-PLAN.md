anomaly_tracked_funnels schema:
  create table public.anomaly_tracked_funnels (
    funnel_id uuid primary key default gen_random_uuid(),
    event_name text not null unique,
    is_enabled boolean not null default true,
    baseline_lookback_days int not null default 7,
    sigma_threshold numeric not null default 2.0,
    created_by uuid references auth.users,
    created_at timestamptz default now()
  );

funnel_anomaly_alerts schema:
  create table public.funnel_anomaly_alerts (
    id uuid primary key default gen_random_uuid(),
    funnel_id uuid not null references anomaly_tracked_funnels(funnel_id),
    fired_at timestamptz not null default now(),
    tick_bucket text not null,    -- date_trunc('minute', fired_at)::text — idempotency key
    observed_count int not null,
    expected_mean numeric not null,
    expected_stddev numeric not null,
    z_score numeric not null,
    resolution_status text not null check (resolution_status in ('firing','resolved','acknowledged')) default 'firing',
    acknowledged_by uuid references auth.users,
    acknowledged_at timestamptz,
    unique (funnel_id, tick_bucket)  -- per Pattern S9 idempotency
  );

SECDEF RPC:
  funnel_anomaly_acknowledge(p_alert_id uuid) returns void
    - raises 'forbidden' (42501) if not is_admin_at_least('admin')
    - updates resolution_status='acknowledged', acknowledged_by=auth.uid(), acknowledged_at=now()
    - audit-log via log_admin_action(action_name='anomaly_acknowledged', target_user_id=null)
    - uses set_config('app.suppress_audit','on',true) per Pattern S3

  funnel_anomaly_baseline_compute(p_event_name text) returns table (...)  -- per RESEARCH Pattern 5
    - SECURITY DEFINER, language sql, STABLE
    - Reads from public.events_mirror (NOT public.events — there is no public.events table in v1.3)
    - Hybrid baseline per D-15: 0.4 × HOD-7d stats + 0.6 × DOW-4w stats

Edge Function contract (supabase/functions/funnel-anomaly-cron/index.ts):
  - Entry: POST handler; checkServiceRoleBearer (per Pattern S6 via _shared/lifecycle-utils.ts makeLazyAdmin)
  - Loop tracked funnels where is_enabled=true
  - For each: call funnel_anomaly_baseline_compute(event_name) via supabase.rpc
  - If z_score < -funnel.sigma_threshold: check 4h suppression (`select max(fired_at) from funnel_anomaly_alerts where funnel_id=...`)
  - If not suppressed: insert alert row with .upsert({onConflict:'funnel_id,tick_bucket', ignoreDuplicates:true}) — idempotency
  - On successful insert: supabase.channel('funnel_anomaly_alerts').send({type:'broadcast', event:'anomaly_fired', payload:{funnel_id, alert_id, fired_at, observed_count, expected_mean, expected_stddev, z_score}}) — Realtime broadcast (alert_id MUST be in payload so banner Ack button knows which row to ack)
  - Then resendDomainHealthCheck() → if verified: sendRoutedEmail({to:SUPERADMIN_ALERTS_EMAIL, template:'anomaly_alert', phi:false, payload:{...}}); else log + 200 {skipped:'resend_unverified'}
  - Return jsonResponse({checked: N, fired: M, suppressed: K})

Realtime channel contract (client side):
  supabase.channel('funnel_anomaly_alerts').on('broadcast', {event:'anomaly_fired'}, handler).subscribe()
  -- Broadcast (NOT postgres_changes) — the cron Edge Fn calls .send() explicitly; avoids ALTER PUBLICATION + bypasses postgres_changes latency
