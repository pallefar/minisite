    `JsonDiffViewer.tsx` — small recursive diff renderer (no library; ~80 LOC). Compute diff via:
    ```typescript
    function diffKeys(a: Record<string, unknown> | null, b: Record<string, unknown> | null) {
      const out: { key: string; status: 'added' | 'removed' | 'changed' | 'unchanged'; before?: unknown; after?: unknown }[] = [];
      const keys = new Set([...(a ? Object.keys(a) : []), ...(b ? Object.keys(b) : [])]);
      for (const k of keys) {
        const inA = a && k in a, inB = b && k in b;
        if (inA && !inB) out.push({ key: k, status: 'removed', before: a![k] });
        else if (!inA && inB) out.push({ key: k, status: 'added', after: b![k] });
        else if (JSON.stringify(a![k]) !== JSON.stringify(b![k])) out.push({ key: k, status: 'changed', before: a![k], after: b![k] });
        else out.push({ key: k, status: 'unchanged', before: a![k], after: b![k] });
      }
      return out.sort((x, y) => x.key.localeCompare(y.key));
    }
    ```

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-24-03c | Tampering | audit_logs DELETE via the archive RPC abused to delete recent rows | mitigate | RPC argument `p_cutoff` constrained `< now() - interval '89 days'` inside the function body; rejects callers passing cutoff > today-89d |
