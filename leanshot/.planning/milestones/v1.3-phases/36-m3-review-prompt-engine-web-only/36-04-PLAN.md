**review_funnel_aggregate RPC** (`supabase/migrations/20270710000006_p36_review_funnel_aggregate_rpc.sql`) — B2/W5 corrected to direct column read:
- Function signature per the interfaces block above.
- Admin gate identical to Wave 1 SECDEF RPCs (`IF NOT EXISTS (SELECT 1 FROM public.profiles WHERE id = auth.uid() AND admin_role IN ('admin','superadmin')) THEN RAISE EXCEPTION 'forbidden'; END IF;`).
- Body — single CTE-style aggregate query (or multiple plpgsql variable assignments):
  ```sql
  v_cutoff timestamptz := now() - (p_window_days || ' days')::interval;

  SELECT
    count(*) AS prompts_shown,
    count(*) FILTER (WHERE rating_value IS NOT NULL) AS rated_internal,
    jsonb_object_agg(
      COALESCE(copy_variant, 'control'),
      jsonb_build_object(
        'prompts_shown', cnt_total,
        'rated_internal', cnt_rated
      )
    ) AS by_variant
  INTO v_prompts, v_rated, v_by_variant
  FROM (
    SELECT
      COALESCE(copy_variant, 'control') AS copy_variant,
      count(*) AS cnt_total,
      count(*) FILTER (WHERE rating_value IS NOT NULL) AS cnt_rated
    FROM public.review_prompt_history
    WHERE fired_at > v_cutoff
    GROUP BY COALESCE(copy_variant, 'control')
  ) per_variant;

  -- external_clicked stays on events_mirror (Pitfall 10 — client-side window.open path):
  SELECT count(*) INTO v_external FROM public.events_mirror
    WHERE event_name = 'external_review_clicked'
      AND captured_at > v_cutoff;

  RETURN QUERY SELECT v_prompts, v_rated, v_external, COALESCE(v_by_variant, '{}'::jsonb);
  ```
