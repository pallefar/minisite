Request (POST):
```typescript
interface DmCreateThreadRequest {
  recipient_user_id: string;
  body: string;            // ≤ 2000 chars; will be dompurified server-side
  attachment_path?: string; // optional dm-attachments path {thread_id}/{message_id}.{ext}
  creator_user_id?: string; // present iff request bears user JWT (must equal JWT.sub); omitted for service-role
}
```

Responses:
- 201 `{ thread_id: string, message_id: string }` on success
- 400 `{ code: 'invalid_body' }` malformed request
- 401 `{ code: 'unauthorized' }` missing/bad bearer
- 403 `{ code: 'identity_mismatch' | 'blocked' | 'dm_closed' }`
- 429 `{ code: 'rate_limited' }` + Header `Retry-After: <seconds>`
- 500 `{ code: 'internal' }` unexpected

Exported for tests:
```typescript
export const __internal = {
  handleDmCreateThread,
  setAdminForTest,
  resetAdminForTest,
};
```
