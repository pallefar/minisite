  - SECDEF RPC: `security definer set search_path = pg_catalog, public, extensions`; Pattern S1 dual-layer (role check inside body); calls log_admin_action

  - 5 standard assertions per file: SELECT cross-tenant returns 0; INSERT cross-tenant fails 42501; UPDATE cross-tenant 0 rows; DELETE cross-tenant 0 rows; same-tenant SELECT returns own rows
