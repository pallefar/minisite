## Spacing Scale

Declared values (all multiples of 4). Source: `src/index.css` `--spacing: 0.25rem` (4px base grid).

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, chip internal padding, inline badge gap |
| sm | 8px | Step-row button cluster gaps, input group padding |
| md | 16px | Card internal padding, drawer section spacing, form field gap |
| lg | 24px | Panel section breaks, step-builder row height separation |
| xl | 32px | Page-level column gap (layout grid), modal body padding |
| 2xl | 48px | Major section breaks between protocol header and step grid |
| 3xl | 64px | Page-level top margin (admin shell already owns this) |

Exceptions:
- Touch targets (Adopt button, AI-assist Suggest button, evidence chip click) minimum 44px height per a11y baseline.
- Step-builder row minimum height 48px to accommodate multi-monitoring multiselect tags.

## Typography

**HARD CEILING: exactly 4 sizes, 2 weights.** (Phase 60 UI-review BLOCKER lesson — enforced by gsd-ui-auditor.)

| Role | Size | Tailwind token | Weight | Line Height | Usage |
|------|------|----------------|--------|-------------|-------|
| Caption / table header | 11px | `text-[11px]` | 400 regular | 1.4 | Column headers, meta labels (week #, version badge), filter-pill counts |
| Body / default UI | 13px | `text-[13px]` | 400 regular | 1.5 | Step rows, evidence chip text, list item copy, drawer body, error messages |
| Sub-heading / action label | 13px | `text-[13px]` | 600 semibold | 1.5 | Section sub-headings, CTA button labels, review banner text, badge labels |
| Section heading | 18px | `text-[18px]` | 600 semibold | 1.35 | Protocol name in editor header, drawer title, modal heading |
| Page heading / display | 28px | `text-heading` | 600 semibold | 1.2 | Page-level heading only — `/admin/protocols` list page H1 and editor H1 |

**Prohibited:** `text-base`, `text-lg`, `text-md`, `text-xl`, `text-2xl`, `text-sm` Tailwind utilities, or any ad-hoc px value outside {11, 13, 18, 28}. Use `text-[11px]`, `text-[13px]`, `text-[18px]`, `text-heading` only.

Font weight usage: `font-normal` (400) for body copy; `font-semibold` (600) for headings, button labels, and section sub-headings. No `font-medium`, `font-bold`, or numeric weight classes.

Mono usage: `font-mono tabular-nums` on `dose_mg` numeric inputs and week-number column in step grid — consistent with RAG queue analog (`RagLayout.tsx` telemetry table pattern).

| Warning — advisory states | `var(--color-warning)` | `#e37748` | AI-assist refusal warning, in_review banner background tint |
| Border | `var(--color-border)` | `#dad3c0` | Step-row separators, drawer border, table grid lines, input borders |
| Text | `var(--color-text)` | `#16221f` | All body copy |
| Text secondary | `var(--color-text-secondary)` | `#4d5e58` | Meta labels, placeholder text, empty state body, week numbers |
| Text tertiary | `var(--color-text-tertiary)` | `#8d958f` | Disabled states, table header labels |

**Accent reserved-for (explicit list — 10% rule):**
1. Primary CTAs: "New Protocol" button (list page), "Publish Protocol" button (reviewer only), "Adopt for patient" button (clinician)
2. Active sub-nav item in ProtocolsLayout sidebar (pill background, matching RagLayout pattern)
3. Evidence chip "Cite evidence" action button border/focus ring
4. AI-assist "Apply suggestion" button
5. Protocol adherence percentage number in BodyTab insights card
6. `aria-current="page"` sub-nav link (active state)

**Accent is NEVER used on:** status badges (use success/danger/warning tokens), decorative labels, informational text, version numbers, monitoring multiselect tags, or any non-interactive chrome.

## Surfaces in Scope

Eight surfaces as declared in CONTEXT.md. Each maps to a specific component file.

### Surface 1: `/admin/protocols` — Protocols List Page

**Analog:** `src/components/admin/rag/RagQueuePage.tsx`
**New file:** `src/components/admin/protocols/ProtocolsListPage.tsx`

Layout: full-width list. Header row: H1 "Protocols" (28px/600) + "New Protocol" CTA (primary button, accent).

List table:
- Columns: Protocol Name (13px/400) | Compound (13px/400) | Audience (Badge chips) | Version (11px/400 mono) | Status (Badge — published=success, draft=border, in_review=warning, archived=text-tertiary) | Last Updated (11px/400 text-secondary) | Actions
- Row hover: `var(--color-admin-table-row-hover)` (#e8e3d5)
- Empty state: heading "No protocols yet" (18px/600) + body "Create your first dosing protocol to distribute to clinicians and patients." (13px/400) + "New Protocol" CTA

Filter pills (reuse Pill DS primitive): All | Published | In Review | Draft | Archived

Keyboard: J/K row navigation, N=new protocol, Shift+?=keyboard help modal.

### Surface 2: `/admin/protocols/:id` — Protocol Editor Page

**Analog:** `src/components/admin/rag/QueueDetailPane.tsx`
**New file:** `src/components/admin/protocols/ProtocolEditorPage.tsx`

Layout: `grid gap-6 lg:grid-cols-[1fr_320px]` — left: step-builder grid; right: metadata panel (compound, audience, version, review state).

**Step-builder grid** (left column):
- Header: Protocol name input (18px/600, editable inline, `Input` DS primitive) + compound picker (select) + audience multiselect (Pill chips — B2C, clinic)
- Step rows: `week` number (11px/400 mono, non-editable label) | `dose_mg` input (13px/400, `font-mono tabular-nums`, min-width 80px) | `frequency` select (daily/weekly/bi-weekly/custom-cron) | `monitoring[]` multiselect pills (weight, glucose, bp, mood, gi-symptoms) | "Cite evidence" button (13px/600, accent border) | AI-assist "Suggest" button (13px/400, secondary style) | Remove row (icon-only, aria-label="Remove step {week}", danger hover)
- Evidence chips: below each step row, `TierBadge`-style chip showing citation text (11px/400, `var(--color-surface-elevated)` background) — click opens `CitationPopover` (Phase 60-10 reuse verbatim)
- Add row: "Add week" button (13px/400, secondary style) — inserts next sequential week number
- No drag-and-drop (CONTEXT.md decision). Insert/remove only.

**Metadata panel** (right column, sticky):
- Protocol name (read-only mirror of left)
- Version badge (11px/400 mono)
- Review state indicator (matching status Badge from list page)
- Created by (13px/400 text-secondary)
- "Save draft" button (secondary)
- "Submit for review" button (primary, accent) — visible to author only
- "Publish" button — visible to reviewer only (author never sees this in DOM — full removal, not disabled)
- "Rollback" link (13px/400, text-danger) — appears when archived versions exist

## Interaction Contracts

### Step-Builder Grid

- Keyboard nav: Tab moves across fields within a row; Shift+Tab reverses; Enter on a row field commits and moves to next row.
- J/K (when focus is on a step row outside inputs): moves between rows.
- Shift+? opens keyboard help modal (QueueKeyboardHelpModal analog).
- "Cite evidence" button: focus opens Evidence Search Sheet (right-side Sheet DS primitive). Sheet closes on Escape.
- "Suggest" button: focus opens AI-Assist Modal. Modal closes on Escape, backdrop click, or Dismiss.
- "Add week" always inserts at end, week number = last_week + 1.
- "Remove step" shows immediate undo Toast (6s). No confirmation modal — step removal is recoverable.
- All inputs in step rows must use `Input` DS primitive with `aria-label="Week {N} {field_name}"`.

### Evidence Search Sheet

- Sheet DS primitive (right-side drawer, 400px wide on lg).
- Search box: `Input` DS primitive, `placeholder="Search RAG evidence…"`, `aria-label="Search RAG evidence"`.
- Results list: top-10 returned by `rag-retrieve`. Each result: chunk title (13px/600) + snippet (13px/400, text-secondary, max 2 lines) + tier badge (TierBadge reuse) + checkbox.
- Checked chunks → "Attach {N} sources" button (accent, primary). Disabled at 0 checked.
- Loading: Skeleton rows (3 × Skeleton DS primitive). `aria-busy="true"` on results container.
- Empty: "No evidence found" EmptyState (inline micro variant).

### 2-Person Review State Machine

Admin UI enforces DOM-level removal of Publish button for authors (not just disabled):
- `current_user_id === protocol.created_by` → Publish button absent from rendered tree entirely (conditional render, not `disabled` + `hidden`).
- Reviewer sees Publish button when `review_state = 'in_review'` and `current_user_id !== protocol.created_by`.
- State transitions reflected immediately in status Badge on list page and editor metadata panel after RPC call.

### Animations

All animations gated on `useReducedMotion()`:
- Sheet entry/exit: `framer-motion` slide-in from right (same as existing Sheet.tsx). `useReducedMotion()` replaces slide with instant mount.
- Modal entry/exit: `framer-motion` fade + scale (same as existing Modal.tsx). Reduced motion: instant mount.
- Toast appear: existing Toast.tsx animation — no changes.
- Skeleton shimmer: CSS `--animate-shimmer`. Disabled via `@media (prefers-reduced-motion: reduce)` in `src/index.css` (already present).

## Accessibility Baseline

All new surfaces must satisfy:

- `aria-label` on every icon-only button (remove step, close sheet, close modal).
- `role="dialog"` + `aria-modal="true"` on all modals and sheets (inherited from DS primitives).
- `aria-live="polite"` on loading regions (evidence search results container, AI suggestion output area).
- `aria-busy="true"` on loading buttons (Apply suggestion during AI fetch, Assign during adopt RPC).
- `aria-current="page"` on active sub-nav link in ProtocolsLayout.
- `aria-sort` on sortable columns in list tables (Protocol Name, Last Updated).
- `aria-invalid` on step-row inputs with validation errors (dose_mg out of range, empty frequency).
- `useReducedMotion()` gates all framer-motion animations.
- `≥44px` touch targets on all action buttons (Adopt for patient, Suggest, Publish Protocol, Cite evidence).
- Focus trap within Sheet and Modal DS primitives (already implemented in DS layer).
- Keyboard-first step-builder: no mouse-only interactions. Every action reachable via Tab + Enter.
