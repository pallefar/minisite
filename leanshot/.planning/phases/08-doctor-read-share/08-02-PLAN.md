<critical_deviations_from_ai_chat>
The `ai-chat/` template is the starting point but THREE places require deviation:

1. **CORS** (Pitfalls 3+4): `ai-chat/cors.ts` uses `Access-Control-Allow-Origin: *` because no cookies. Share function ships cookies → MUST echo the request `Origin` from a server-side allow-list (production SPA origin + Vercel preview deploy origins) and set `Access-Control-Allow-Credentials: true`. Browser-spec-forbidden combo: `*` + `credentials: include`.

2. **Rate limit** (Pitfall 5): `ai-chat/rate-limit.ts` keys on `user_id` (JWT). Share `/redeem` has no JWT. Key on `share_id` instead — call `increment_share_attempt(share_id)` RPC after each failed `crypt()` compare; if return value > 5 within 60s window → 429. Use `last_attempt_at` timestamp on `shares` to reset counter when older than 60s.

3. **JWT verification**: `ai-chat` requires `Authorization: Bearer <user-JWT>`. Share endpoints do NOT — `/redeem` has no auth (code IS the auth), `/snapshot` auth is the HttpOnly cookie. Do NOT call `admin.auth.getUser(token)` in this function.
</critical_deviations_from_ai_chat>

    **`supabase/functions/share/hash.ts`**:
    ```typescript
    export async function sha256Hex(input: string): Promise<string> {
      const buf = new TextEncoder().encode(input);
      const digest = await crypto.subtle.digest('SHA-256', buf);
      return Array.from(new Uint8Array(digest))
        .map((b) => b.toString(16).padStart(2, '0'))
        .join('');
    }

    export function parseUaFamily(ua: string): string {
      // Crude family parse — Chrome / Firefox / Safari / Edge / Other
      if (/Edg\//.test(ua)) return 'Edge';
      if (/Chrome\//.test(ua)) return 'Chrome';
      if (/Firefox\//.test(ua)) return 'Firefox';
      if (/Safari\//.test(ua)) return 'Safari';
      return 'Other';
    }

    export function parseIpFamily(xff: string): string {
      // Just the leading /16 to avoid storing PII-grade precision
      const ip = xff.split(',')[0]?.trim() ?? '';
      const parts = ip.split('.');
      if (parts.length === 4) return `${parts[0]}.${parts[1]}.0.0/16`;
      // IPv6: collapse to /48
      if (ip.includes(':')) return ip.split(':').slice(0, 3).join(':') + '::/48';
      return 'unknown';
    }
    ```

    Deno.serve(async (req: Request): Promise<Response> => {
      const cors = buildCorsHeaders(req);
      if (req.method === 'OPTIONS') return new Response('ok', { headers: cors });

      const url = new URL(req.url);
      const headers = { ...BASE_RESPONSE_HEADERS, ...cors };

      try {
        if (url.pathname.endsWith('/redeem') && req.method === 'POST') {
          return await handleRedeem(req, headers);
        }
        if (url.pathname.endsWith('/snapshot') && req.method === 'GET') {
          return await handleSnapshot(req, headers);
        }
        return jsonError(404, 'not-found', headers);
      } catch (err) {
        console.error('share fn error', err);
        return jsonError(500, 'internal', headers);
      }
    });

    function jsonError(status: number, code: string, headers: Record<string, string>, extra: Record<string, unknown> = {}): Response {
      return new Response(JSON.stringify({ error: code, ...extra }), { status, headers });
