## Phase Goal

**As a** GLP-1 patient who's been using LeanShot locally, **I want to** create an account with email + password, verify my email, and securely sign in on any browser, **so that** my data is tied to a real identity and I can sign in on a second device to begin cross-device sync.

> Per ROADMAP §"Phase 5" `**Mode:** mvp` — this plan ships the auth surfaces end-to-end so SC#2 (password reset) and SC#3 (signout + cache clear) become PROVEN. SC#1 ships its first leg (signup → verify → signin); 05-03 ships the cross-device Realtime completion. SC#4 (offline-first) becomes available because addInjection enqueues `pendingOps` once 05-03 wires the queue — this plan adds the gate predicate (`isSyncEnabled(session)`) so the gate is testable before the queue flush exists.
