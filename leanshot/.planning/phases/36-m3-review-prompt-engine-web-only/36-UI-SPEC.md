## Spacing Scale

All Tailwind v4 spacing utilities resolve against `--spacing: 0.25rem` (4px base) defined in `src/index.css:128`. Declared values for this phase:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Star-button gap; chip-padding inset |
| sm | 8px | Form field gaps inside rule-builder card; modal header→body gap |
| md | 16px | Default modal padding; section padding inside admin page; rating-row spacing |
| lg | 24px | Card padding (admin rule-builder list rows, funnel chart card); modal footer gap |
| xl | 32px | Vertical gap between admin page sections (rule list ↔ funnel chart) |
| 2xl | 48px | Empty-state vertical padding; modal hero illustration block |

**Exceptions:** none. Star tap targets honor the 44px native-touch floor by combining `xs` gap (4) + `28px` glyph + symmetrical `sm` (8) padding → 44px total — composed from the scale, not a fixed exception.

## Typography

LeanShot Design System v2 already defines a 10-step type scale. This phase declares **4 sizes + 2 weights** drawn from that scale:

| Role | Token | Size | Weight | Line Height |
|------|-------|------|--------|-------------|
| Body | `text-base` | 16px | 400 (regular) | 1.55 |
| Label | `text-sm` | 13px | 600 (semibold) | 1.5 |
| Heading | `text-xl` | 22px | 600 (semibold, Geist) | 1.35 |
| Display (modal title only) | `text-2xl` | 26px | 600 (semibold, Fraunces) | 1.25 |

**Weight policy:** 2 weights total (regular 400, semibold 600). NO weight 500 (medium) or 700 (bold) introduced on these surfaces.

**Font-family policy:** Body + label + heading = Geist (var `--font-sans`). Display = Fraunces (var `--font-display`) — only on consumer-facing modal titles (Surface A/B/C). Admin surfaces (D/E/F) use Geist throughout (heading included) to match Phase 24/27/34/35 admin precedent.

**Numeric (star count, funnel %):** Geist Mono via `--font-mono`, weight 600, tabular-nums.

## Color

All colors resolve via existing semantic tokens — no raw hex in components per `src/index.css` Anti-Pattern #5.

| Role | Token | Value (light) | Usage |
|------|-------|---------------|-------|
| Dominant (60%) | `--color-bg` / `--color-surface` | cream-100 #f2ede0 / cream-card #fefcf7 | Modal backdrop blur surface; admin page background; rule-builder card surface |
| Secondary (30%) | `--color-surface-soft` / `--color-surface-elevated` | #ebe7dc / #f6f2e8 | Empty-state panels; un-selected star rest state; funnel-chart axis cells |
| Accent (10%) | `--color-primary` (teal-700) #1b4842 | Reserved-for list ↓ | Selected star fill; primary CTA button background; rule-active pill background |
| Destructive | `--color-danger` (clay) #cf5454 | (none in this phase) | Reserved for delete-rule confirmation only — see Copywriting Contract |
| Success | `--color-success` (sage) #45b077 | Funnel "external-review-posted" bar fill; rule-fired toast confirmation |
| Warning | `--color-warning` (orange) #e37748 | A/B variant "not statistically significant yet" badge; CTA-catalog v1.4 row badge |

**Accent (`--color-primary`) reserved exclusively for:**
1. Selected star fill in Surface A (NPS prompt)
2. Primary CTA button background ("Submit", "Rate now", "Save rule")
3. Active-rule pill in Surface D rule-list (single visual indicator)
4. "Ship Winner" button background in Surface E (mirrors `OnboardingABPanel` contract)
5. Funnel-chart "internal-rating" bar fill in Surface E

**Accent NOT used for:** un-selected stars (use `--color-text-tertiary`), secondary buttons (use border + `--color-text`), table-row hover, modal backdrop, or any text body. Per `[[ui_checker_dimension_traps]]` — accent budget capped at 5 elements above.

**Dark mode:** Every token above has a `[data-theme='dark']` counterpart already shipped in `src/index.css`. No new dark-mode token introduced. Verify via Surface A/B/C/D/E screenshot pair at checker time.

## Surface-Specific Contracts

### Surface A — NPS Prompt Modal (5★ rating)

| Spec | Value |
|------|-------|
| Shell | `<Modal size="sm" dismissible mobileFullscreen={false}>` |
| Trigger | `useNPSPromptListener()` hook subscribed to D-01 whitelist events |
| Title (Fraunces 26/1.25, semibold) | "How likely are you to recommend LeanShot to a friend?" |
| Body copy (Geist 16/1.55, regular) | "Your feedback helps us improve. Takes 5 seconds." |
| Rating control | 5 star buttons, lucide-react `Star` glyph, 28px, 44px tap target, ARIA `aria-label={"Rate {n} of 5 stars"}` per star, `role="radiogroup"` wrapper |
| Star states | Un-selected: `text-[var(--color-text-tertiary)]` + stroke-only. Hover/keyboard-focus: `text-[var(--color-primary)]` + stroke. Selected: `text-[var(--color-primary)]` + fill. Animation: 200ms `var(--ease-out-quart)` color transition; respects `useReducedMotion()` (no transition when reduced). |
| Submit CTA | Disabled until rating selected; primary variant; label = "Submit rating" |
| Dismiss | Top-right `X` (`IconButton`) + backdrop click. **Both count as fired prompt per D-12** — no warning copy that says "this will count" (would game the cooldown). |
| Forbidden | No copy/UI indicator of cooldown state, lifetime cap, or "you'll see this in N days". Per CONTEXT prompt constraints. |
| Forbidden (V13-3) | No import from `@/hooks/useNativeReviewTrigger` or `@/lib/native/review-shim` inside the rating-decision path. ESLint AST rule blocks it (D-03). |
| Reduced motion | Entry animation = opacity fade only (no scale, no slide) when `useReducedMotion()` is true. |

### Surface B — Promoter External-CTA Modal (4-5★)

| Spec | Value |
|------|-------|
| Shell | `<Modal size="sm" dismissible>` |
| Title (Fraunces 26/1.25) | "Help others find LeanShot" |
| Body copy (Geist 16/1.55) | "Takes 30 seconds — would you share your experience on {platform}?" — `{platform}` resolved server-side per D-14 cohort lookup (Trustpilot for consumer; G2 / Capterra for clinic). |
| CTA buttons | One primary button per resolved platform (max 2). Label = "Review on {Platform}" + external-link `ExternalLink` lucide icon trailing. Secondary button: "Not now" (ghost variant, dismiss). |
| Click behavior | Opens platform URL in new tab (`target="_blank" rel="noopener noreferrer"`). Fires `external_review_clicked` PostHog event with platform property (D-15). No completion polling. |
| Vendor-block fallback | If `review_cta_catalog` returns 0 rows for cohort (Trustpilot not yet claimed — D-16 vendor gate), render single-line message "Thanks for the rating!" with no CTA. Surface still opens (so user perceives feedback), modal auto-dismisses after 1.5s. |
| Forbidden | No mention of Apple App Store / Google Play (those rows are `requires_mobile_shell=true` per D-13; filtered out server-side in v1.3). |

| Spec | Value |
|------|-------|
