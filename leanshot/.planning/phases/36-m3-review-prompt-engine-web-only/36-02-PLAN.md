Cooldown rules (D-05/D-06/D-07/D-08 — W7 clarifies sliding-window semantics):
- Lifetime: count(review_prompt_history WHERE user_id=$U) >= 5 → fire=false reason=lifetime_cap
- Detractor flag (W7 SLIDING WINDOW): `EXISTS (SELECT 1 FROM review_prompt_history WHERE user_id = $U AND rating_value <= 2 AND fired_at > now() - interval '90 days')`. NOT lifetime — the flag is active ONLY while a low rating sits inside the trailing 90d window. A user who rated 2 at day -100 reverts to 60d cooldown (per W7 boundary test case).
- Global cooldown: minGlobalDays = detractorFlag ? 90 : 60. Last `fired_at` + minGlobalDays > now → fire=false reason=global_cooldown.
- Per-rule: max(fired_at WHERE rule_id=$R) < 30d → reject this rule (try next eligible).
- All checks on `review_prompt_history` (web quota); native_review_prompts is SEPARATE (D-19).
