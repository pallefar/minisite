## Implementation Decisions

### Frontend lint scope (137 errors)
- **106 `import-x/order`** — dominant. ESLint config sets `'newlines-between': 'never'` and alphabetized groups. Most failures: blank lines in import blocks; some misordered imports; some interleaved with `vi.mock`, comments, or `lazy()` declarations.
  - **Strategy:** per-file restructure. For test files with `vi.mock` between imports, leverage Vitest's auto-hoist of `vi.mock` and move ALL imports to a contiguous top block. For App.tsx and similar with `lazy()` declarations between imports, move all `import` statements before any `const X = lazy(...)`.
- **31 jsx-a11y/* errors** across rules: label-has-associated-control (11), click-events-have-key-events (10), no-static-element-interactions (7), no-noninteractive-element-interactions (3). Mechanical patterns:
  - label associations: add `htmlFor` + matching `id`
  - click handlers without keyboard: add parallel `onKeyDown` for Enter/Space, or convert `<div onClick>` to `<button>`
- **2 no-unused-vars + 1 misc** — quick local edits.

### RPC body lint scope (35 errors)
Two dominant patterns:
1. **`character varying(255)` vs `text` mismatches** (~5+ occurrences in RETURN QUERY). Fix: cast `::text` in the SELECT body OR change function return-type signature to `varchar(255)`.
2. **`rag_vendor = text` operator missing** in `public.rag_acknowledge_budget_cap`. Fix: cast `$1::rag_vendor` at the comparison.

Each fix lands as a **retroactive forward-timestamped migration** wrapping `DROP FUNCTION IF EXISTS <name>(<args>) CASCADE; CREATE FUNCTION ...`. Per `feedback_phase_close_out_supabase_gotchas` (1): bare `CREATE FUNCTION` (no `IF NOT EXISTS`).
