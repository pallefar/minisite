**Migration 005 (log_phi_access RPC):** Header cites Phase 25 D-07, Pattern S1+S7, RESEARCH Pitfall 5 (search_path).

```sql
create or replace function public.log_phi_access(
  p_accessed_user_id uuid,
  p_accessed_fields text[],
  p_reason text,
  p_accessed_org_id uuid default null
)
returns void
language plpgsql
security definer
set search_path = public, extensions, pg_catalog
as $$
declare
  v_actor uuid := auth.uid();
begin
  if v_actor is null then
    raise exception 'not_authenticated' using errcode = '28000';
  end if;
  if p_accessed_user_id is null then
    raise exception 'invalid_arguments: p_accessed_user_id required' using errcode = '22023';
  end if;
  insert into public.phi_access_log
    (actor_user_id, accessed_user_id, accessed_org_id, accessed_fields, reason)
  values
    (v_actor, p_accessed_user_id, p_accessed_org_id, p_accessed_fields, p_reason);
end;
$$;

revoke all on function public.log_phi_access(uuid, text[], text, uuid) from public;
grant execute on function public.log_phi_access(uuid, text[], text, uuid) to authenticated;
```

Notable choices (per [[feedback_planner_iter1_anti_patterns]]):
- T-25-02-04 mitigation: actor_user_id sourced from `auth.uid()` — NEVER from a request argument (parallel to ai-chat T-04-04 invariant).
- Pattern S7: `set search_path = public, extensions, pg_catalog` per RESEARCH Pitfall 5 — without this, an attacker who SET search_path could shadow `public.phi_access_log` with a malicious table.
- DO NOT pre-validate `accessed_fields` length in plpgsql — let the DDL check do it (single source of truth; avoids the "defensive jsonb contracts" anti-pattern).

**Client wrapper `src/lib/hipaa/phi-access-rpc.ts`:**

Import supabase from `@/lib/supabase`. Export:
```typescript
export type PhiAccessArgs = {
  accessedUserId: string;
  accessedFields: string[];
  reason: string;
  accessedOrgId?: string | null;
};

export async function logPhiAccess(args: PhiAccessArgs): Promise<void> {
  try {
    const { error } = await supabase.rpc('log_phi_access', {
      p_accessed_user_id: args.accessedUserId,
      p_accessed_fields: args.accessedFields,
      p_reason: args.reason,
      p_accessed_org_id: args.accessedOrgId ?? null,
    });
    if (error) {
      // T-25-02-S3: log error.name only, never error.message
      console.warn('[hipaa/phi-access] rpc rejected', error.code ?? 'unknown');
    }
  } catch (e) {
    console.warn('[hipaa/phi-access] threw', e instanceof Error ? e.name : 'unknown');
  }
}
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| patient→DB | Patient SELECTs own access log; RLS predicate `accessed_user_id = auth.uid()` enforces |
| staff→DB | Staff SELECTs all access logs via `public.is_admin_at_least('staff'::public.admin_role)` predicate |
| authenticated→RPC | Any authenticated user can INVOKE log_phi_access; actor_user_id derived from auth.uid not arg |
| service_role→DB | Edge fns and admin tooling can INSERT (e.g., backfill); UPDATE/DELETE explicitly REVOKED |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-25-02-01 | Tampering | phi_access_log past rows | mitigate | Append-only RLS + service_role REVOKE update,delete |
| T-25-02-02 | Information disclosure | cross-patient access log read | mitigate | RLS `accessed_user_id = auth.uid()` + staff override via `public.is_admin_at_least('staff'::public.admin_role)`; no other read path |
| T-25-02-03 | Repudiation | attacker forges actor_user_id | mitigate | RPC sources actor_user_id from `auth.uid()` only; arg is ignored (parallel T-04-04 invariant) |
| T-25-02-04 | Spoofing | unauthenticated RPC invocation | mitigate | RPC raises `not_authenticated` when auth.uid is null; grant execute restricted to authenticated role |
| T-25-02-05 | Information disclosure | reason text containing PHI | accept | Reason is staff-authored free-text; we document at RPC level "reason must NOT contain patient identifiers"; future audit-of-audit could lint this |
| T-25-02-06 | Denial of service | spamming RPC fills table | accept | Low write volume per D-07 (per page-open / per export); no per-actor rate limit at v1.3; revisit if log row count exceeds 1M/quarter |
</threat_model>
