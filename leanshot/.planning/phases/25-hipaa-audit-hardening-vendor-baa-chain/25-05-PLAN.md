**`scripts/lint-stripe-phi.ts`** (or `.mjs` per Decision rule above):

Header per Pattern S8:
```
// scripts/lint-stripe-phi.ts
// Phase 25 Plan 25-05 — HIPAA-08 banking-exemption boundary CI gate.
//
// What it does:
//   Scans .ts/.tsx files under src/ and supabase/functions/ that import or
//   reference `stripe`. For each stripe.<resource>.<verb>({...}) call site,
//   extracts string-literal argument values from description, statement_descriptor,
//   metadata, and line_items[].description fields. Fails if any value contains
//   a keyword from stripe-phi-keywords.json (case-insensitive, word-boundary
//   anchored per RESEARCH Pitfall 11).
//
// Allowlist:
//   Inline `// stripe-phi-lint:allow reason='...'` on the same line OR within
//   3 lines above the matched call expression. Comment without reason= is
//   REJECTED (forces engineer to document intent).
//
// CLI flags:
//   --json           Emit JSON report instead of human/CI-annotation form.
//   --strict         Treat warnings as errors (default: errors only fail; no warnings exist yet).
//   --root=PATH      Override scan root (default: cwd which CI sets to leanshot/).
//
// Exit codes:
//   0 = PASS
//   1 = FAIL (violation(s) found)
//   2 = USAGE ERROR (bad CLI args)
//
// GitHub Actions annotation:
//   ::error file=PATH,line=N::keyword "<KW>" in stripe API call argument
```

Implementation outline (~250 lines, zero deps if possible; use `node:fs` + `node:path`):
1. Parse CLI args.
2. Load `scripts/stripe-phi-keywords.json` → keyword list (lowercased + escaped for regex).
3. Recursively walk `src/` and `supabase/functions/`, filtering by extension (`.ts`, `.tsx`) AND excluding `node_modules`, `dist`, `.next`, test files (`*.test.*`, `*.spec.*`, `__tests__`).
4. For each file: if file content does NOT match `/\bstripe\b/i` skip (fast-path; most files irrelevant).
5. For each matched file, scan for stripe call expressions. Use a hand-rolled regex (NOT AST): `/(?:stripe|[A-Za-z_][\w]*Stripe)\.\w+\.(create|update|capture|refund|cancel|retrieve|del|list)\s*\(\s*\{([^}]*)\}/gs` to capture the object literal body. This is intentionally LOOSE — it accepts false positives in the call-site detection (the keyword-in-value check then narrows). Refine over time per RESEARCH Pitfall 11 "AST upgrade only if false-positive rate >10%/month."
6. Within each call-site object body, scan for `description: '...'`, `statement_descriptor: '...'`, `metadata: { ... }`, `line_items: [...]` — extract string-literal values. Use regex `/(?:description|statement_descriptor)\s*:\s*['"`]([^'"`]+)['"`]/g` plus a recursive jsonish-ish extractor for metadata values.
7. For each extracted value: lowercase, scan for `\\b<keyword>\\b` (word boundary) for each keyword. Multi-word keywords (`blood pressure`, `GLP-1`) match literally.
8. On match: check for allowlist comment on the same line or within 3 lines above. Regex: `/\/\/\s*stripe-phi-lint:allow\s+reason=['"]([^'"]+)['"]/`. If matched + reason non-empty → suppress this finding. If matched without reason= → REJECT (lint failure: "allowlist comment missing reason=").
9. Emit findings:
   - `--json`: array of `{file, line, column, keyword, callSite, suggestion}`.
   - Default: `::error file=PATH,line=N::keyword "<KW>" found in stripe API call. Add `// stripe-phi-lint:allow reason='<why-this-is-safe>'` if intentional.`
10. Exit 0 if zero findings, 1 otherwise.

CRITICAL: per CLAUDE.md project skills GSD enforcement, the script MUST be runnable via plain `node` from CI's `leanshot/` cwd. Test by invoking from a different cwd and confirming `--root=.` adapts.

**`scripts/__tests__/lint-stripe-phi.test.ts`** (vitest):

2. **Keyword in description fails:** `stripe.charges.create({ description: 'Refund for Ozempic dose' })` → exit 1 + stderr contains `::error` + `Ozempic`.
3. **Allowlist comment with reason passes:** preceding comment `// stripe-phi-lint:allow reason='patient-month metering label, not PHI'` + same code as case 2 → exit 0.
4. **Allowlist without reason fails:** `// stripe-phi-lint:allow` (no `reason=`) + violation → exit 1.
5. **Keyword in non-stripe call passes:** `notStripe.charges.create({ description: 'Ozempic' })` → exit 0 (fast-path skips file without `stripe` identifier; OR call-site regex doesn't match).

7. **Partial word does NOT trigger:** `metadata: { type: 'patientId-token' }` — `patient` is part of `patientId` so word-boundary `\\bpatient\\b` should NOT match. Asserts NO failure. (This is the RESEARCH Pitfall 11 verification.)

9. **Test file excluded:** fixture in `__tests__/` directory with violation → exit 0 (test files excluded per scan rules).
10. **JSON mode emits valid JSON:** invoke `--json`; parse stdout; assert array shape.
