CONTRACT 1 — `public.profiles` table (created OR extended)
  Columns (NEW table form, if `profiles` doesn't already exist):
    id          uuid PRIMARY KEY REFERENCES auth.users(id) ON DELETE CASCADE
    is_staff    boolean NOT NULL DEFAULT false
    created_at  timestamptz NOT NULL DEFAULT now()
  Trigger: on `auth.users` AFTER INSERT — insert a matching `public.profiles` row.
  Idempotent: use `create table if not exists`; if the table exists, ALTER ADD COLUMN
  IF NOT EXISTS for `is_staff` and ensure the auth-user backfill trigger is in place.

CONTRACT 2 — `public.is_staff()` helper
  RETURNS boolean
  LANGUAGE sql
  STABLE
  SECURITY DEFINER
  SET search_path = public, extensions, pg_catalog
  Body: SELECT coalesce((SELECT is_staff FROM public.profiles WHERE id = auth.uid() LIMIT 1), false)
  GRANT EXECUTE ON FUNCTION public.is_staff() TO authenticated, anon;
  (anon receives false; authenticated receives the row's is_staff or false)

CONTRACT 3 — `public.landing_pages` table
  id                      uuid PK default gen_random_uuid()
  slug                    text NOT NULL UNIQUE
  title                   text NOT NULL DEFAULT ''
  status                  text NOT NULL DEFAULT 'draft' CHECK (status IN ('draft','published'))
  published_revision_id   uuid                              (FK added in migration 03 — DEFERRABLE INITIALLY DEFERRED)
  seo_title               text
  seo_description         text
  seo_og_image            text
  seo_canonical           text
  seo_schema_type         text NOT NULL DEFAULT 'WebPage'
  created_by              uuid REFERENCES auth.users(id) ON DELETE SET NULL
  created_at              timestamptz NOT NULL DEFAULT now()
  updated_at              timestamptz NOT NULL DEFAULT now()
  Trigger: BEFORE UPDATE → set updated_at = now()

CONTRACT 4 — `public.landing_page_revisions` table (APPEND-ONLY)
  id           uuid PK default gen_random_uuid()
  page_id      uuid NOT NULL REFERENCES public.landing_pages(id) ON DELETE CASCADE
  block_tree   jsonb NOT NULL DEFAULT '[]'::jsonb
  created_by   uuid REFERENCES auth.users(id) ON DELETE SET NULL
  created_at   timestamptz NOT NULL DEFAULT now()
  -- No updated_at column. Append-only.
  Index: (page_id, created_at desc)
  Triggers (migration 10): BEFORE UPDATE → raise exception; BEFORE DELETE → raise
  exception UNLESS deletion cascades from `landing_pages` parent (detect via
  pg_trigger_depth() > 0 OR a `set local app.allow_revision_cascade = 'true'`
  GUC — pick one and document in the file).

CONTRACT 5 — `public.leads` table
  id                uuid PK default gen_random_uuid()
  page_id           uuid REFERENCES public.landing_pages(id) ON DELETE SET NULL
  email             text NOT NULL
  name              text
  extra_fields      jsonb NOT NULL DEFAULT '{}'::jsonb
  ip_hash           text                                   -- SHA-256 of client IP; PII-safe
  honeypot_flagged  boolean NOT NULL DEFAULT false
  created_at        timestamptz NOT NULL DEFAULT now()
  Index: (page_id, created_at desc); (created_at desc) for staff dashboards.

CONTRACT 6 — `public.site_settings` (singleton)
  id                   uuid PK default gen_random_uuid()
  site_name            text NOT NULL DEFAULT 'LeanShot'
  default_description  text
  favicon_url          text
  default_og_image     text
  updated_at           timestamptz NOT NULL DEFAULT now()
  Singleton enforcement: `create unique index site_settings_singleton on public.site_settings ((true))`
  Initial row: `insert into public.site_settings (site_name) values ('LeanShot') on conflict do nothing`

CONTRACT 7 — `page-assets` Storage bucket
  id / name:           'page-assets'
  public:              false (RLS-gated reads + service-role / signed-URL for renderer)
  file_size_limit:     10485760 (10 MB)
  allowed_mime_types:  array['image/jpeg', 'image/png', 'image/webp', 'image/gif']
  Idempotent insert with `on conflict (id) do update`.

CONTRACT 8 — RLS POLICY MATRIX (named policies — exact names below)
  landing_pages:
    pol_landing_pages_public_select_published   FOR SELECT  TO anon, authenticated  USING (status = 'published')
    pol_landing_pages_staff_all                 FOR ALL     TO authenticated         USING (public.is_staff())  WITH CHECK (public.is_staff())
  landing_page_revisions:
    pol_landing_page_revisions_public_select_published
        FOR SELECT TO anon, authenticated
        USING (EXISTS (SELECT 1 FROM public.landing_pages p
                       WHERE p.published_revision_id = landing_page_revisions.id
                         AND p.status = 'published'))
    pol_landing_page_revisions_staff_select_all   FOR SELECT TO authenticated USING (public.is_staff())
    pol_landing_page_revisions_staff_insert       FOR INSERT TO authenticated WITH CHECK (public.is_staff())
    -- NO update / delete policies — append-only enforced by RLS absence + trigger.
  leads:
    pol_leads_service_role_insert  FOR INSERT TO service_role WITH CHECK (true)
    pol_leads_staff_select         FOR SELECT TO authenticated USING (public.is_staff())
    -- NO update / delete policies — leads are immutable from app code.
  site_settings:
    pol_site_settings_public_select  FOR SELECT TO anon, authenticated USING (true)
    pol_site_settings_staff_update   FOR UPDATE TO authenticated       USING (public.is_staff())  WITH CHECK (public.is_staff())
    pol_site_settings_staff_insert   FOR INSERT TO authenticated       WITH CHECK (public.is_staff())
  storage.objects (bucket_id='page-assets'):
    pol_page_assets_public_select    FOR SELECT TO anon, authenticated
        USING (bucket_id = 'page-assets')                      -- public images served via Storage URL
    pol_page_assets_staff_insert     FOR INSERT TO authenticated
        WITH CHECK (bucket_id = 'page-assets' AND public.is_staff())
    pol_page_assets_staff_update     FOR UPDATE TO authenticated
        USING (bucket_id = 'page-assets' AND public.is_staff())
    pol_page_assets_staff_delete     FOR DELETE TO authenticated
        USING (bucket_id = 'page-assets' AND public.is_staff())
  Note: the SELECT policy is permissive (bucket is effectively a public CDN) but
  LISTING (which uses the same SELECT policy at the metadata level) is the
  surface D-13 cares about — staff need to list, non-staff get only items
  attached to currently-published pages OR an empty list. Tighten if necessary
  to `AND (public.is_staff() OR EXISTS (...))` per analog `20260801000003_org_logos_storage.sql`.

CONTRACT 9 — file naming and ordering
  All 10 migration files use the prefix `20261101000001_` through `20261101000010_`.
  They MUST be created and committed in numeric order — `supabase db push` applies
  them in lexicographic order. Order encodes correctness: helper before policies
  that reference it; tables before FK; trigger after table.
