## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| visitor browser → `/{slug}` route | Untrusted path input; the `vercel.json` rewrite decides whether a path reaches the public `page-render` Edge Function or an app surface |
| rendered landing page → embedded third-party iframe | Rendered pages embed Calendly / YouTube / Tally content via iframes; `frame-src` is the only thing constraining which origins can be framed |
| public visitor → `admin-bundle` / `vendor-dnd-kit` chunks | The editor bundle must never be downloadable by, or reachable from, a public page load |
