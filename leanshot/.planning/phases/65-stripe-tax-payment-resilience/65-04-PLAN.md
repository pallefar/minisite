<interfaces>
From invoice-payment-failed.ts (existing, ~32 lines):
- `export async function handle(event: Stripe.Event, admin: SupabaseClient): Promise<void>` — receives `event.data.object as Stripe.Invoice`, reads `invoice.subscription` (subscription_id), updates `subscriptions` set `ux_tier='past_due'` + `status='past_due'`.

New shape after this plan:
- The handler ALSO reads the row's current `dunning_state`, computes the NEXT state per the transition table below, and writes BOTH `ux_tier='past_due'` AND `dunning_state=<next>` AND `last_dunning_email_at=null` (null signals "next email is owed; orchestrator cron will pick up").
- Transition table (per CONTEXT.md D-07):
  - `null` or `'none'` → `'first_failed'`
  - `'first_failed'` → `'second_failed'`
  - `'second_failed'` → `'final_warning'`
  - `'final_warning'` → stays `'final_warning'` (no further advance; Stripe will trigger subscription.updated→canceled which moves to `cancelled_for_payment`)
  - `'cancelled_for_payment'` → no-op (already terminal)

From subscription-updated.ts: existing handler maps Stripe subscription.status → subscriptions.status/ux_tier. Add: when `event.data.object.status === 'canceled'` AND prior `dunning_state IN ('first_failed','second_failed','final_warning')`, set `dunning_state='cancelled_for_payment'`.

From checkout-session-completed.ts: existing handler creates the subscription mapping. Add two write paths:
1. If `session.customer_tax_ids?.length > 0` AND the session is a clinic plan (detect via subscription_data.metadata.tier_kind === 'clinic' OR price_id matches STRIPE_PRICE_CLINIC_BASE), pick the FIRST tax_id from `session.customer_tax_ids` (which is `Array<{ type, value }>`) and upsert `org_subscriptions.tax_id = value` keyed by the clinic_id resolved from session metadata.
2. If `session.automatic_tax?.status === 'complete'` (or `'requires_location_inputs'` for log-everything visibility), call `writeTaxCollectionLog(admin, session)` from the new helper — captures customer_state, tax_amount_cents, subtotal_cents, total_cents, tax_rate_percent, automatic_tax_status.
</interfaces>
