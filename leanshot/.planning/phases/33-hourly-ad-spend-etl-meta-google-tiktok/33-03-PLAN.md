API endpoint reference (from RESEARCH):
- Meta: GET https://graph.facebook.com/v25.0/act_{AD_ACCOUNT_ID}/insights
  Required params: breakdowns=hourly_stats_aggregated_by_advertiser_time_zone, level=ad, fields=ad_id,ad_name,campaign_id,adset_id,spend,clicks,impressions,actions, action_attribution_windows=["7d_click"]
  DO NOT include: reach, frequency (incompatible with hourly breakdown)
  Rate limit: parse x-business-use-case-usage header; if total_cputime > 80% warn + return partial

- Google: POST https://googleads.googleapis.com/v24/customers/{CUSTOMER_ID}/googleAds:searchStream
  Auth: Bearer {access_token from OAuth2 exchange} + developer-token header + login-customer-id header
  OAuth2 exchange: POST https://oauth2.googleapis.com/token with client_id, client_secret, refresh_token, grant_type=refresh_token
  GAQL: SELECT ad_group_ad.ad.id, campaign.id, ad_group.id, metrics.clicks, metrics.cost_micros, metrics.impressions, metrics.conversions, segments.date, segments.hour FROM ad_group_ad WHERE segments.date BETWEEN '{since}' AND '{until}'
  cost_micros: divide by 1_000_000 for USD amount

- TikTok: GET https://business-api.tiktok.com/open_api/v1.3/report/integrated/get/
  Auth: Access-Token header (NOT Authorization: Bearer)
  Required params: advertiser_id, report_type=BASIC, data_level=AUCTION_AD, dimensions=["ad_id","stat_time_hour"], metrics=["spend","impressions","clicks","conversions"], start_date, end_date
  Retry: exponential backoff on 429 + 5xx, max 3 attempts, per-request timeout 15s

- ECB: GET https://www.ecb.europa.eu/stats/eurofxref/eurofxref-daily.xml
  Parse: <Cube time="{YYYY-MM-DD}"> and <Cube currency="{CODE}" rate="{value}"/>
  Use: ON CONFLICT (currency, rate_date) DO NOTHING (weekend days have no new publication)

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| pg_cron → Edge Function HTTP invoke | cron SQL calls via service-role bearer; Edge Fn validates bearer |
| Edge Function → Meta/Google/TikTok API | outbound credential flow; tokens in Function Secrets |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-33-03-01 | Information Disclosure | API credentials in Deno.env logs | mitigate | Never log token values; log only `credentials_present: true/false` in writeHealth |
| T-33-03-02 | Spoofing | Unauthorized POST to ETL endpoints | mitigate | `checkServiceRoleBearer(req)` validates Bearer token on every request; 401 on mismatch |
| T-33-03-03 | Denial of Service | TikTok 429 storm fills cron queue | mitigate | Max 3 retries + exponential backoff; after max retries, cron exits with 500 and next tick retries |
| T-33-03-04 | Information Disclosure | Meta BUC header logged verbatim (may contain account metadata) | mitigate | Log only `total_cputime` + `total_time` numeric values, not the full BUC JSON |
| T-33-03-05 | Tampering | FX rate poisoning via DNS spoofing of ECB endpoint | accept | ECB is official source; HTTPS enforces cert chain; low-value attack vector for ad-spend context |
</threat_model>
