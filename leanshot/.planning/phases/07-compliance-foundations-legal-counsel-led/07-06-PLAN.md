<objective>
Extend the local-only `exportData()` in `SettingsPage.tsx:94-122` to fulfill the **export half** of COMPL-06: a user clicks one button and receives a **complete, portable, patient-readable** record of their LeanShot data. Two artifacts produced per click-flow:

1. **`leanshot-export-YYYY-MM-DD.json`** — machine-readable; existing local entities **plus** cloud ground-truth for the 9 sync tables **plus** `ai_messages` count **plus** an `audit_logs` SUMMARY block (counts per action, NOT raw rows — Open Question #5 default per researcher).
2. **`leanshot-export-YYYY-MM-DD.pdf`** — human-readable patient rollup: cover page (email, export date), per-entity tables (last N rows per entity for size control), photo summary (count + earliest/latest date, NOT bytes), AI conversation count, audit-log summary.

Purpose: COMPL-06 requires "data export" before broad public launch (WMHMDA right-to-access; FTC HBNR breach-disclosure investigation aid; baseline GDPR-style portability even though we are not GDPR-bound). v1 ships the **mechanism**; a formal portability schema (FHIR, vCard) is explicitly deferred per CONTEXT.md.

**Mandatory constraint:** Per memory `project_phase5_bundle_regression.md` + Phase 6 D-12, **direct static imports of jsPDF/jspdf-autotable from App.tsx, main.tsx, store.ts, or SettingsPage.tsx-top-level are regressions blocked by the bundle-size CI guard**. The 50 kB index gz ceiling cannot absorb a ~50-60 kB-gz jsPDF on top. This plan ships:
- Dynamic `await import('jspdf')` + `await import('jspdf-autotable')` **inside** the export click handler.
- An **extended** CI bundle-budget assertion that pins the jsPDF chunk shape (separate chunk exists, size sane).

Output: 4 source/test artifacts + 1 CI guard. Phase 7 COMPL-06 (export half) closes.

    ```typescript
          import('jspdf-autotable'),
        ]);
        const autoTable = autoTableMod.default;

        // Same cloud + audit fetch as JSON path — keep the two payloads coherent.
        let cloud: CloudExtras | null = null;
        let audit: AuditSummary | null = null;
        if (userId) {
          const [c, a] = await Promise.all([
            fetchCloudExtras(supabase, userId).catch(() => null),
            fetchAuditSummary(supabase, userId).catch(() => null),
          ]);
          cloud = c;
          audit = a;

        const payload = buildJsonExport(pickPartialized(fullState), cloud, audit);

        // Yield to the browser between sections to keep the UI responsive
        // (Threat #4 — DoS via main-thread freeze). buildPdfDoc itself is
        // synchronous; the yield happens here, between the data fetch and the
        // render, AND inside buildPdfDoc between table sections (Task 1 step 3
        // already builds the layout linearly — if a future profiling pass
        // shows >250 ms freeze, split buildPdfDoc into an async generator that

        await new Promise((resolve) => setTimeout(resolve, 0));

        toast('PDF exported', 'success');
      } catch (e) {
        console.error('[leanshot] PDF export failed', e);
        toast('PDF export failed', 'error');
      }
    };
    ```

    ```bash
    #!/usr/bin/env bash
    #
    # assert-bundle-budget.sh
    #
    # Phase 7 Plan 07-06 chunk-shape guard for jsPDF + jspdf-autotable.
    # COMPL-06 ships a PDF export that dynamic-imports jspdf inside the
    # Settings Export-PDF click handler. The bundle ceiling enforced by
    # assert-vendor-react-size.sh (index gz ≤ 50,000 bytes) holds only if
    # jspdf stays in its own lazy chunk. This script pins that topology:
    #
    #   1. dist/assets/jspdf-*.js chunk MUST exist (separate from index).
    #   2. jspdf chunk gzipped size MUST be > 20,000 bytes (sanity floor —
    #      if it's tiny, jsPDF was tree-shaken away → PDF export is broken).
    #   3. (Optional in v1) dist/assets/jspdf-autotable-*.js MUST exist
    #      OR be inlined into the jspdf chunk (Vite may merge them).
    #
    # On any guard violation: emit a GitHub Actions ::error:: annotation
    # and exit 1. On all guards passing: emit a single OK line and exit 0.
    #
    # See memory project_phase5_bundle_regression.md for the original
    # Phase 5 regression class this script defends against.

    set -euo pipefail

    SCRIPT_DIR="$(cd "$(dirname "$0")" && pwd)"
    DIST_DIR="$(cd "$SCRIPT_DIR/.." && pwd)/dist"
    ASSETS_DIR="$DIST_DIR/assets"

    JSPDF_FLOOR=20000

    PHASE_REF=".planning/phases/07-compliance-foundations-legal-counsel-led/07-06-PLAN.md"

    if [ ! -d "$ASSETS_DIR" ]; then
      echo "::error::dist/assets not found at $ASSETS_DIR — run 'npm run build' first" >&2
      exit 1
    fi

    # Locate jspdf chunk (exclude .map source maps).
    JSPDF_MATCHES=()
    while IFS= read -r f; do
      JSPDF_MATCHES+=("$f")
    done < <(find "$ASSETS_DIR" -maxdepth 1 -type f -name 'jspdf-*.js' ! -name '*.map' 2>/dev/null)

    JSPDF_COUNT=${#JSPDF_MATCHES[@]}
    if [ "$JSPDF_COUNT" -eq 0 ]; then
      echo "::error::no jspdf-*.js chunk emitted in $ASSETS_DIR — jspdf may have been static-imported into the index chunk OR tree-shaken away. See $PHASE_REF" >&2
      exit 1
    fi

    # Sum gzipped size across all jspdf-*.js chunks (Vite may emit jspdf + jspdf-autotable separately or merged).
    TOTAL_JSPDF=0
    for f in "${JSPDF_MATCHES[@]}"; do
      sz=$(gzip -c "$f" | wc -c | tr -d '[:space:]')
      TOTAL_JSPDF=$((TOTAL_JSPDF + sz))
    done

    if [ "$TOTAL_JSPDF" -lt "$JSPDF_FLOOR" ]; then
      echo "::error::jspdf chunk(s) only $TOTAL_JSPDF bytes gzipped (floor $JSPDF_FLOOR) — jspdf was likely tree-shaken or stub-replaced. Phase 7 Plan 07-06 expects a real jsPDF runtime. See $PHASE_REF" >&2
      exit 1
    fi

    # Final cross-check: verify jspdf is NOT in the index chunk by grepping the
    # index chunk source for the jsPDF API surface name. This is a coarse signal
    # (a comment or string could falsely match), but a direct static import would
    # absolutely include the constructor name.
    IDX_MATCHES=()
    while IFS= read -r f; do
      IDX_MATCHES+=("$f")
    done < <(find "$ASSETS_DIR" -maxdepth 1 -type f -name 'index-*.js' ! -name '*.map' 2>/dev/null)

    if [ ${#IDX_MATCHES[@]} -eq 1 ]; then
      IDX_FILE="${IDX_MATCHES[0]}"
      # The jsPDF constructor identifier appears uniquely in the runtime source.
      # If we see it in the index chunk, jspdf was statically imported somewhere.
      if grep -q "jsPDF" "$IDX_FILE"; then
        echo "::error::index chunk ($IDX_FILE) contains 'jsPDF' identifier — jspdf was statically imported, regressing the index gz ceiling. Move the import to a dynamic await import('jspdf') inside a click handler. See $PHASE_REF" >&2
        exit 1
      fi
    fi

    echo "jspdf bundle topology OK: $JSPDF_COUNT chunk(s), total gz $TOTAL_JSPDF bytes (floor $JSPDF_FLOOR); index chunk free of jsPDF identifier"
    exit 0
    ```
