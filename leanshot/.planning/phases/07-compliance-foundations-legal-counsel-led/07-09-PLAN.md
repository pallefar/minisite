From src/components/dashboard/charts/MedLevelChart.tsx (the canonical template):
```tsx
export function MedLevelChart({ height = 280 }: { height?: number }) {
  // Nullable selector — accept `user` may be null mid-transient.
  const u = useStore((s) => s.user);
  const injections = useStore((s) => s.injections);
  const { theme } = useTheme();

  const config = useMemo(() => {
    if (!u) return null;            // memo body short-circuits on null user
    // ... derivations that reference u.medication, u.units, etc.
    return { /* ... */ };
  }, [u, injections, theme]);

  if (!u || !config) return null;   // early-return AFTER all hooks
  return <BaseChart config={config} ... />;
}
```

Key rules (from research §9 + verified in MedLevelChart):
1. The `useStore((s) => s.user)` selector returns `User | null` — keep the variable name `u` (matches existing call sites).
2. The early-return `if (!u) return null;` MUST come AFTER all `useStore`, `useMemo`, `useEffect`, `useTheme`, `useToast`, etc. hook calls. Never put it before a hook.
3. If a `useMemo` body dereferences `u.field`, the memo body MUST short-circuit on null: `if (!u) return null;` (or a sensible empty value) at the top of the memo. The memo's deps still include `u`.
4. If a `useEffect` body dereferences `u.field`, the effect body MUST short-circuit on null: `if (!u) return;`. The effect's deps still include `u`.
5. The narrowed type post-guard is `User` (not `User | null`) — TS flow analysis handles this without an assertion. If TS can't narrow across a closure (rare), use a `const user = u;` local capture inside the closure, NOT a non-null assertion.
