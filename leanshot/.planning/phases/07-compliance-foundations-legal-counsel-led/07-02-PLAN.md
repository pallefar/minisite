### Hosting-mechanism decision — SPA hash routes (Shape A)

Justified against the 50 kB index gz ceiling (memory: `project_phase5_bundle_regression.md` — Phase 6 Plan 06-01 deferred-init pattern is the project rule for heavy SDKs):

| Option | Mechanism | Bundle Impact | Verdict |
|---|---|---|---|
| **A: SPA hash routes** (CHOSEN) | `#/legal/*` → React component via `App.tsx` view selector + `React.lazy()` | Each page in its own lazy chunk; ZERO impact on `index.js` entry graph | Matches existing `#/auth/*` precedent. Zero new infra. |
| B: Static MD via Vercel rewrites | `/public/legal/*.md` + rewrite to MD viewer | Zero SPA bundle impact, but adds Vercel-rewrite config + a MD renderer dep (~10-15 kB gz) for the viewer | Heavier than A once viewer is counted. |
| C: In-bundle MD components (statically imported) | `import md from './privacy.md'` (with Vite MD plugin) | MD plugin pulls into entry graph; remark/rehype are heavy | Direct violation of 50 kB ceiling rule. |

**Choice: Shape A.** Same routing primitive Phase 5 D-01 already battle-tested; lazy boundaries already understood; bundle guard already enforces lazy-only hosting of new surfaces; researcher concurs (07-RESEARCH §2 Recommendation). Decision recorded in plan; do not re-litigate at execution time.
