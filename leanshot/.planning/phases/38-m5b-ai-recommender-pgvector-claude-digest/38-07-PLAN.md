Algorithm:

2. Detect at-risk users (D-09 verbatim — single threshold):
```sql
SELECT u.id AS user_id, u.email, p.timezone, u.last_event_at
FROM (
  SELECT id, email,
    GREATEST(
      (SELECT max(occurred_at) FROM injection_log WHERE user_id = users.id),
      (SELECT max(occurred_at) FROM weight_log WHERE user_id = users.id),
      (SELECT max(occurred_at) FROM mood_log WHERE user_id = users.id),
      (SELECT max(occurred_at) FROM meal_log WHERE user_id = users.id)
    ) AS last_event_at
  FROM auth.users users
) u
JOIN public.profiles p ON p.id = u.user_id
WHERE u.last_event_at < now() - interval '14 days'
  AND NOT EXISTS (
    SELECT 1 FROM public.win_back_sends wbs
    WHERE wbs.user_id = u.user_id
      AND wbs.last_sent_at > now() - interval '30 days'
  )
LIMIT 500;
```
