Migration `20270705000020_phase38_hitl_decision_rpc.sql`:
- `CREATE OR REPLACE FUNCTION public.hitl_decide(row_ids uuid[], decision text, note text DEFAULT NULL, edited_payload jsonb DEFAULT NULL) RETURNS TABLE (id uuid, status text) LANGUAGE plpgsql SECURITY INVOKER SET search_path=public,extensions AS $fn$ BEGIN IF NOT (SELECT app.is_super_admin(auth.uid())) THEN RAISE EXCEPTION 'super-admin only'; END IF; IF decision NOT IN ('approved','rejected','edited') THEN RAISE EXCEPTION 'invalid decision'; END IF; UPDATE public.ai_suggestion_review SET status = decision, decided_by = auth.uid(), decided_at = now(), decision_note = note, payload = COALESCE(edited_payload, payload) WHERE id = ANY(row_ids) AND status = 'pending' RETURNING id, status; END; $fn$;`
- GRANT EXECUTE TO authenticated.
