|-------|-------|-------|

## Typography

**HARD CEILING: exactly 4 sizes, 2 weights.** (Phase 60 UI-review BLOCKER lesson — enforced by gsd-ui-auditor.)

| Role | Size | Tailwind token | Weight | Line Height | Usage |
|------|------|----------------|--------|-------------|-------|
| Caption / table header | 11px | `text-[11px]` | 400 regular | 1.4 | Column headers, meta labels (epsilon value, cohort size count, version badges, week-bin labels in charts), filter-pill counts, DP methods footer values |
| Body / default UI | 13px | `text-[13px]` | 400 regular | 1.5 | Cohort filter row labels, cross-tab cell values, retention curve legend text, publication list body, consent modal body text, error messages, DP footer prose |
| Sub-heading / action label | 13px | `text-[13px]` | 600 semibold | 1.5 | Section sub-headings, CTA button labels, review banner text, k_floor suppressed message, publication status badge labels |
| Section heading | 18px | `text-[18px]` | 600 semibold | 1.35 | Chart panel headings, cohort builder section heading, publication editor title, modal heading, drawer title |
| Page heading / display | 28px | `text-heading` | 600 semibold | 1.2 | Page-level H1 only — `/admin/research` H1, publication editor H1. Public `/research/<slug>` H1 uses `text-heading` with `font-display` (Fraunces) per Knowledge hub analog |

**Prohibited:** `text-base`, `text-lg`, `text-md`, `text-xl`, `text-2xl`, `text-sm` Tailwind utilities, or any ad-hoc px value outside {11, 13, 18, 28}. Use `text-[11px]`, `text-[13px]`, `text-[18px]`, `text-heading` only.

Font weight usage: `font-normal` (400) for body copy; `font-semibold` (600) for headings, button labels, and section sub-headings. No `font-medium`, `font-bold`, or numeric weight classes.

Mono usage: `font-mono tabular-nums` on epsilon display values, cohort size numbers, suppressed-bucket count, k_floor estimated-size badge — consistent with Phase 61 step-builder dose field pattern.

Display (Fraunces) usage: public `/research/<slug>` H1 only — mirrors `KnowledgeArticleDetailPage.tsx` H1 pattern. Admin and settings surfaces use sans only.

## k_floor Sentinel UX Contract

When cohort builder estimates size < 5:
1. Estimated size counter display is replaced with the warning string `Cohort too small (k<5) — broaden filters` (13px/600, `var(--color-warning)`, `AlertTriangle` icon)
2. "Run Cohort" button is `aria-disabled="true"` + `opacity-50` + non-clickable (pointer-events-none)
3. Button tooltip on hover/focus: "Cohort must have at least 5 users to preserve privacy" (13px/400)
4. This is the ONLY visual pathway — no silent submission, no empty chart, no 400 error displayed

When size >= 5 and size <= 50: epsilon reminder displayed `epsilon = 1.0 (admin output; public = 0.5)` (11px/400, `font-mono`, text-secondary). Admin sees closer-to-truth output; public publications always use `epsilon = 0.5`.

## Interaction Contracts

### Cohort Builder Form

- Filter changes trigger debounced (400ms) estimated-cohort-size RPC call.
- k_floor check evaluated on every estimate update — warning appears/disappears in real time.
- "Run Cohort" POST to `compile_research_cohort` SECDEF RPC.
- Successful run: retention chart + cross-tab matrix populate with animation (`animate-fade-in`).
- Suppressed RPC response (`{suppressed: true, reason: 'k_floor'}`): chart remains empty + banner "Cohort suppressed — k<5 at the selected filters." (13px/600, `var(--color-warning)`) renders ABOVE chart area.
- Loading: "Run Cohort" button shows `aria-busy="true"` + spinner during RPC. Chart area shows Skeleton rows.

### Publication Editor

- Markdown path auto-populated from `content/research/*.md` dropdown (13px/400, `font-mono`).
- "Save Draft" available always; "Submit for Review" only when draft saved.
- 2-person review DOM rule: author never sees "Publish Research" button in rendered tree.
- Status Badge updates immediately after RPC call.
- Keyboard: Tab/Shift+Tab; Escape closes any open drawer/modal.

### Research Consent Toggle

- Toggle change to OFF: always opens revoke confirmation modal (never fire-and-forget).
- Toggle change to ON: no confirmation — silent enable + success Toast "Research consent enabled."
- Focus-visible ring: `var(--color-primary)` outline per DS global `:focus-visible` rule.

### 2-Person Review State Machine

Mirrors Phase 61 `ProtocolReviewBanner` logic exactly:
- `current_user_id === publication.created_by` → "Publish Research" button absent from rendered tree.
- Reviewer sees "Publish Research" when `status = 'in_review'` and `current_user_id !== publication.created_by`.
- State transitions reflected immediately in status Badge on list page and metadata panel after RPC call.

### Public Research Pages

- No auth wall on `/research/*`. `robots=index`. No login prompt.
- DP Methods Footer rendered on every `/research/<slug>` — never optional, never behind a toggle.
- RSS link at `/research/rss.xml` always visible at top of index page.
- OG image generated via `@vercel/og` Edge Fn — displayed in social share previews.

### Animations

All animations gated on `useReducedMotion()` (mirrors Phase 61 contract exactly):
- Chart reveal: `animate-fade-in` (`var(--duration-standard)` 300ms). Reduced motion: instant mount.
- Sheet entry/exit: `framer-motion` slide-in from right (Sheet DS primitive). Reduced motion: instant.
- Modal entry/exit: `framer-motion` fade + scale (Modal DS primitive). Reduced motion: instant.
- Toast appear: existing Toast.tsx animation — no changes.
- Skeleton shimmer: CSS `--animate-shimmer`. Disabled via `@media (prefers-reduced-motion: reduce)` already in `src/index.css`.
