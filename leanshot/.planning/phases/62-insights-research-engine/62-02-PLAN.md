1. **public.laplace_noise(value numeric, epsilon numeric)** RETURNS numeric LANGUAGE plpgsql SECURITY DEFINER SET search_path = public, pg_temp.
   - Generate uniform u in (0,1) from gen_random_uuid() entropy. Use the substring → bit(32) → int → float8 transform from RESEARCH Pattern 2:
     `u := (('x' || substr(replace(gen_random_uuid()::text, '-', ''), 1, 8))::bit(32)::int::float8 / 2147483647.0 + 1.0) / 2.0;`
   - b := 1.0 / NULLIF(epsilon, 0);
   - RETURN value + (-b * SIGN(u - 0.5) * LN(1.0 - 2.0 * ABS(u - 0.5)));
   - Edge case: when value IS NULL return NULL.
   - REVOKE ALL ON FUNCTION public.laplace_noise(numeric, numeric) FROM public; GRANT EXECUTE ON FUNCTION public.laplace_noise(numeric, numeric) TO authenticated.
   - This RPC does NOT need is_staff() guard — it's a pure math helper called by other SECDEF functions and only granted to authenticated.
