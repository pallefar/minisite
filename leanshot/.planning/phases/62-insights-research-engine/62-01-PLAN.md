Create migration at supabase/migrations/20290102000002_insights_matviews.sql. Wrap in begin/commit.

Create 5 materialized views per INSIGHTS-03/04 (week-level binning + HAVING count(distinct user_id) >= 5 + ZERO PHI columns in SELECT list):

1. **insights_dose_rollup** — source: public.injections JOIN public.profiles ON p.id = i.user_id. Columns: week_bin (date_trunc('week', i.injected_at)::date), compound (i.medication_id::text), tenure_bucket (CASE on age(now(), p.created_at) → '<3m' / '3-6m' / '6-12m' / '12m+'), audience_segment (p.goal_type::text), cohort_n (count(distinct i.user_id)), avg_dose_mg (avg(i.dose_mg)), stddev_dose_mg (stddev(i.dose_mg)), injection_count (count(i.id)). WHERE p.research_consent = true. GROUP BY 1,2,3,4. HAVING count(distinct i.user_id) >= 5.

2. **insights_body_metrics_rollup** — source: public.weights JOIN profiles. Columns: week_bin (date_trunc('week', w.logged_at)::date), tenure_bucket, audience_segment, cohort_n, avg_weight_kg (avg(w.weight_kg)), stddev_weight_kg. WHERE p.research_consent = true. HAVING count(distinct w.user_id) >= 5.

3. **insights_retention_rollup** — source: profiles. Columns: cohort_week (date_trunc('week', p.created_at)::date), audience_segment, tenure_bucket (use age vs cohort_week or fixed bucket), cohort_n (count(distinct p.id)), retention_30d (count distinct cases where exists injection within 30d of created_at / total), retention_90d. WHERE p.research_consent = true. HAVING count(distinct p.id) >= 5.

4. **insights_engagement_rollup** — source: public.community_engagement JOIN profiles (skip if community_engagement absent on remote — fall back to ai_messages alone with a comment noting the absence; planner verified Phase 41 community_engagement may exist). Columns: week_bin (date_trunc('week', ce.at)::date), audience_segment, tenure_bucket, kind (ce.kind), cohort_n, event_count. WHERE p.research_consent = true. HAVING cohort_n >= 5.

5. **insights_ai_interaction_rollup** — source: public.ai_messages JOIN profiles. Columns: week_bin (date_trunc('week', am.created_at)::date), audience_segment, tenure_bucket, role (am.role), model_bucket (am.model_used), cohort_n (count distinct am.user_id), message_count (count am.id). WHERE p.research_consent = true. HAVING cohort_n >= 5.

For each matview:

- Create UNIQUE INDEX on natural key (per RESEARCH Open Question 3 — REFRESH CONCURRENTLY requires it):

  - insights_body_metrics_rollup: (week_bin, tenure_bucket, audience_segment)
  - insights_retention_rollup: (cohort_week, audience_segment, tenure_bucket)
  - insights_engagement_rollup: (week_bin, audience_segment, tenure_bucket, kind)
  - insights_ai_interaction_rollup: (week_bin, audience_segment, tenure_bucket, role, model_bucket)
- All matviews are `CREATE MATERIALIZED VIEW IF NOT EXISTS` for idempotency.

CRITICAL — PHI gate enforcement:
