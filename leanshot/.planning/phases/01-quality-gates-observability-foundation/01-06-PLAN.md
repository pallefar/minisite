    ```yaml
    name: CI

    on:
      push:
        branches: [main]
      pull_request:
        branches: [main]

    # Cancel in-flight runs for the same branch/PR on a new push (Discretion)
    concurrency:
      group: ${{ github.workflow }}-${{ github.ref }}
      cancel-in-progress: true

    jobs:
      lint:
        name: Lint
        runs-on: ubuntu-latest
        steps:
          - uses: actions/checkout@v4
          - uses: actions/setup-node@v4
            with:
              node-version: '22'
              cache: 'npm'
          - run: npm ci
          - run: npm run lint

      format-check:
        name: Format check
        runs-on: ubuntu-latest
        steps:
          - uses: actions/checkout@v4
          - uses: actions/setup-node@v4
            with:
              node-version: '22'
              cache: 'npm'
          - run: npm ci
          - run: npm run format:check

      typecheck:
        name: Typecheck
        runs-on: ubuntu-latest
        steps:
          - uses: actions/checkout@v4
          - uses: actions/setup-node@v4
            with:
              node-version: '22'
              cache: 'npm'
          - run: npm ci
          - run: npm run typecheck

      test-unit:
        name: Unit tests
        runs-on: ubuntu-latest
        steps:
          - uses: actions/checkout@v4
          - uses: actions/setup-node@v4
            with:
              node-version: '22'
              cache: 'npm'
          - run: npm ci
          - run: npm run test:unit

      test-e2e:
        name: E2E smoke + production-build security check
        runs-on: ubuntu-latest
        steps:
          - uses: actions/checkout@v4
          - uses: actions/setup-node@v4
            with:
              node-version: '22'
              cache: 'npm'
          - run: npm ci

          - name: Install Playwright Chromium
            run: npx playwright install chromium --with-deps

          # Production-shaped build with explicitly empty env vars.
          # Asserts S-10: production build with empty Sentry DSN exits 0.
          - name: Build (production-shaped, empty env)
            run: npm run build
            env:
              VITE_SENTRY_DSN: ''
              VITE_POSTHOG_KEY: ''
              VITE_POSTHOG_HOST: ''
              VITE_ANALYTICS_ENABLED: 'false'

          # Security check (T-1-05 mitigation): the dev-only Sentry trigger string
          # 'phase-1-sentry-smoke' MUST NOT appear in any production-built JS file.
          # Vite tree-shakes the import.meta.env.DEV branch out of production builds.
          - name: Security check — dev-only trigger absent from production build
            run: |
              if grep -r "phase-1-sentry-smoke" dist/ ; then
                echo "FAIL: dev-only Sentry trigger 'phase-1-sentry-smoke' leaked into production bundle"
                exit 1
              fi

          - name: Run Playwright smoke against production build
            run: npm run test:e2e
            env:
              CI: 'true'

          - name: Upload Playwright report on failure
            if: failure()
            uses: actions/upload-artifact@v4
            with:
              name: playwright-report
              path: playwright-report/
              retention-days: 7
    ```

    Key design decisions per RESEARCH.md and CONTEXT.md:

    1. **5 named jobs** matching the CI gate list (D-03): `lint`, `format-check`, `typecheck`, `test-unit`, `test-e2e`.
    2. **Node 22 LTS, single version** (Discretion + matches v22.18.0 dev machine).
    3. **`concurrency` cancel-in-progress** (Discretion).
    4. **`cache: 'npm'`** on every setup-node (faster CI).
    5. **No Playwright browser caching** — per RESEARCH.md, restore time ≈ download time so caching is not worth the complexity.
    6. **Empty env vars on the production build** — asserts S-10 + the no-op Sentry path (`enabled: !!import.meta.env.VITE_SENTRY_DSN` from Plan 05 returns false when DSN is empty).
    7. **Security grep check** — T-1-05 mitigation. The dev-only `throw new Error('phase-1-sentry-smoke')` from Plan 05 is wrapped in `import.meta.env.DEV`, which Vite tree-shakes in production builds. The `grep` step asserts the string is absent from `dist/` — if a future regression compiles the throw into prod, this CI step blocks the PR.
    8. **Playwright run uses `CI: 'true'`** — playwright.config.ts switches to `npm run preview` (port 4173) in CI mode so the e2e smoke runs against the production build, not dev.
    9. **Artifact upload on failure** — stores the playwright-report for diagnosis, retained 7 days.
    10. **No source-map upload** — deferred to Phase 2 per D-11 + CONTEXT.md.

    Note on T-1-04 (forks/secrets): This CI workflow does NOT inject any secrets (no `${{ secrets.* }}` references). The only sensitive build inputs are VITE_* env vars and they are explicitly empty in the e2e job. Future phases that need secrets (e.g., Phase 2 deploy) can add a fork guard like `if: github.event.pull_request.head.repo.full_name == github.repository`. Phase 1 is unaffected — captured here for cross-phase awareness.
