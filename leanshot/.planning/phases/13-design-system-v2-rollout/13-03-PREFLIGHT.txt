D. StreakBadge file shape decision
----------------------------------
Decision: SINGLE component + `tier` prop (per plan recommendation).
Rationale: Bundle prototype is a SINGLE-component shape (variant + locked). Plan dictates
new API (tier: bronze|silver|gold|locked). Following the plan's interfaces block exactly:
  export type StreakTier = 'bronze' | 'silver' | 'gold' | 'locked';
  export interface StreakBadgeProps { tier: StreakTier; className?: string; }
The 4 reference SVGs (streak-bronze/silver/gold/locked.svg) inform the 4 tier visuals.
Locked SVG is a simple lock-icon variant; bronze/silver/gold differ only by gradient palette
+ corner number (7/30/90). We'll reproduce the bundle SVGs inline (gradient stops use hex
because each tier's bronze/silver/gold palette is a deliberate brand-locked gradient —
documented exception per CLAUDE.md "hex literals OK in gradient stops only").
