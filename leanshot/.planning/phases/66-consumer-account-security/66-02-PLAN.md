```ts
export type Aal2ConsumerPurpose = 'delete-account' | 'export-all-data' | 'change-email';

export async function requireAal2ForConsumerAction(
  supabase: SupabaseClient,
  purpose: Aal2ConsumerPurpose,
  opts?: { freshWindowMs?: number; onChallenge?: () => Promise<{ code: string } | { cancelled: true }> }
): Promise<{ ok: true } | { ok: false; reason: 'mfa_not_enabled' | 'cancelled' | 'invalid_code' | 'session_stale' }>;
```

Behavior:
- If user's `mfa_factors` is empty → return `{ ok: false, reason: 'mfa_not_enabled' }` and caller proceeds (gate doesn't apply if MFA not enrolled — per D-02)
- If AAL is already `aal2` AND `isAal2Fresh()` (default 15min) → return `{ ok: true }`
- Else call `opts.onChallenge` (UI hooks present modal); on `{ code }` → `verifyTotpChallenge`; on success persist freshness timestamp + return `{ ok: true }`

Test:
- No MFA → `{ ok: false, reason: 'mfa_not_enabled' }`
- Fresh AAL2 → `{ ok: true }` without calling onChallenge
- Stale AAL2 + valid code → `{ ok: true }`
- Stale AAL2 + cancelled → `{ ok: false, reason: 'cancelled' }`
- Stale AAL2 + invalid code → `{ ok: false, reason: 'invalid_code' }`
