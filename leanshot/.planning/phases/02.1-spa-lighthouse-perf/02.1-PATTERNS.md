# Phase 2.1 Patterns Map

**Purpose:** Help executor agents bootstrap by pointing each new/modified file to its closest existing analog in the codebase. Bootstrap reading should be cheap — read the analog once, then the new task description does the rest.

**Convention:** "Analog" = the file with the most similar shape (purpose, structure, conventions) that already lives in the repo. "Why" explains what to copy from the analog and what to deliberately NOT copy.
