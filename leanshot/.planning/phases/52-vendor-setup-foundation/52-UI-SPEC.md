# Phase 52 — UI Design Contract

> Visual and interaction contract for the single staff-only admin surface shipped in this phase:
> the `vendor_smoke_log` admin module at `/admin/vendor-smoke`.
>
> Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> All design decisions are pre-populated from: existing DS tokens in `src/index.css`,
> existing admin component patterns in `src/components/admin/`, and locked decisions in
> `52-CONTEXT.md`. No user questions were required.

---

## Scope

**One surface only:** `AdminVendorSmokeDashboard` — a staff-gated admin module that
surfaces the per-vendor smoke-test results from the `vendor_smoke_log` table. There is
no consumer-facing UI in this phase. Do not invent additional screens.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (LeanShot custom DS) |
| Preset | not applicable |
| Component library | LeanShot `src/components/ui/` primitives (Card, CardHeader, Badge, Button, EmptyState, Toast/useToast) |
| Icon library | lucide-react ^0.460.0 |
| Font | Geist (sans), Geist Mono (mono) — loaded via `index.html` |

**DS source of truth:** `src/index.css` `@theme {}` block. All color references MUST use
`var(--color-*)` tokens. No hard-coded hex values in component source.

## Spacing Scale

Tailwind v4 spacing scale only. No bespoke spacing values.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px (`gap-1`, `p-1`) | Icon gaps, badge leading-icon gap |
| sm | 8px (`gap-2`, `p-2`) | Row action button gap, inline chip gap |
| md | 16px (`p-4`, `gap-4`) | Table cell padding, card interior horizontal |
| lg | 24px (`p-6`, `mb-6`) | Card padding (CardHeader `mb-4` + body), section break |
| xl | 32px (`mb-8`) | Page header to first card separation |
| 2xl | 48px | Not used in this module |
| 3xl | 64px | Not used in this module |

Exceptions: table cells use `px-4 py-3` (16px / 12px) following the exact
`AdminAffiliatesReviewQueue` precedent.

## Typography

Drawn exclusively from the LeanShot ceiling (11 / 13 / 18 / 28 px). No new sizes.

| Role | Size | Weight | Line Height | Token |
|------|------|--------|-------------|-------|
| Table cell body | 13px (`text-sm`) | 400 regular | 1.5 | `--text-sm` |
| Column header / label caps | 11px (`text-[11px]`) | 600 semibold | 1.4 | `--text-micro` |
| Page heading | 18px (`text-lg`) | 600 semibold | 1.5 | `--text-lg` |
| Sub-heading / page description | 13px (`text-sm`) | 400 regular | 1.5 | `--text-sm` |

Weights declared: **400 regular** and **600 semibold** only. Bold (700) is NOT used in
this module (admin table pattern does not use bold outside KPI tiles).

Column header caps follow `AdminAffiliatesReviewQueue` exactly:
`text-xs font-semibold uppercase tracking-[0.06em] text-[var(--color-text-secondary)]`
which resolves to 12px; that falls within the 11px ceiling approximation (12px is the
`text-xs` step). If the checker flags this, use `text-[11px]` instead for strict compliance.

## Color

60 / 30 / 10 split — all tokens from `src/index.css @theme`.

| Role | Token | Value (light) | Usage |
|------|-------|---------------|-------|
| Dominant (60%) | `--color-bg` | `#f2ede0` cream-100 | Page background |
| Secondary (30%) | `--color-surface` / `--color-surface-elevated` | `#fefcf7` / `#f6f2e8` | Cards, table rows, nav |
| Accent (10%) | `--color-primary` | `#1b4842` teal-700 | "Run smoke now" primary Button only |
| Destructive | `--color-danger` / `--color-danger-soft` | `#cf5454` / `#f8dbdb` | `fail` status badge background+text |

**Accent reserved for:** the single "Run smoke now" `<Button variant="primary" size="sm">` in the
`CardHeader` action slot. Accent is NOT used on status badges, table rows, or secondary controls.

**Status badge semantic mapping** — uses existing `BadgeTone` values only:

| Smoke status | Badge tone | DS tokens used |
|---|---|---|
| `ok` | `success` | `--color-success-soft` bg + `--color-success` text |
| `fail` | `danger` | `--color-danger-soft` bg + `--color-danger` text |
| `not_configured` | `neutral` | `--color-surface-elevated` bg + `--color-text-secondary` text + `--color-border` border |

No new badge tones. No new color tokens.

## Component Inventory

Every element maps to an existing DS primitive. No bespoke components beyond composition.

### `AdminVendorSmokeDashboard` (new file)

**Location:** `src/components/admin/AdminVendorSmokeDashboard.tsx`

**Layout:** Full-width `<main>` with `p-6` padding, `min-h-screen bg-[var(--color-bg)]`,
identical to `AdminAffiliatesReviewQueue` outer shell.

**Structure:**

```
<main> (p-6, min-h-screen)
  <header> (flex, justify-between, items-center, mb-6)
    <div>
      <h1>  — page title, text-lg font-semibold tracking-tight
      <p>   — description, text-xs text-[--color-text-secondary]
    </div>
    (no top-level CTA here — CTA lives inside CardHeader action slot)
  </header>

  <Card span={12} variant="default" padding="none">
    <CardHeader
      title="Vendor integrations"
      icon={<ShieldCheck size={16} aria-hidden />}
      action={<RunSmokeButton />}
    />
    <table>  — vendor smoke log table (see below)
    or
    <EmptyState> — if vendor_smoke_log has zero rows
  </Card>
```

### Table: Vendor smoke log

Modeled on `AdminAffiliatesReviewQueue` table and `BaaChainTable`. Keyboard-navigable
(`tabIndex={0}` on `<tr>` rows, `role="row"`, `scope="col"` on `<th>`).

**Columns:**

| Column | Width guidance | Content |
|---|---|---|
| Vendor | auto | Vendor name (`font-medium`) |
| Status | 100px | `<Badge tone={...}>` with status label |
| Last checked | 130px | ISO → `toLocaleDateString` formatted timestamp, `text-[var(--color-text-secondary)]` |
| Latency | 80px | `{ms}ms` tabular-nums; `—` when null; `text-[var(--color-text-secondary)]` |
| Message | auto | Short error or `—`; `text-xs font-mono text-[var(--color-text-secondary)]`; truncated with `max-w-[40ch] truncate` |

Column header class (exact): `text-xs font-semibold uppercase tracking-[0.06em] text-[var(--color-text-secondary)] px-4 py-3`

Row class: `border-b border-[var(--color-border)] last:border-b-0`

Row hover: `hover:bg-[var(--color-surface-elevated)]` — no click action on rows (read-only).

### `RunSmokeButton` (inline sub-component)

Renders inside `CardHeader` `action` slot.

- Default state: `<Button variant="primary" size="sm" leadingIcon={<Play size={14} aria-hidden />}>Run smoke now</Button>`
- Loading state: `<Button variant="primary" size="sm" loading aria-busy="true" role="status">Running…</Button>`
- The button sets `aria-busy` during the async Fn invocation; Toast confirms result on completion.

### Status badges

```tsx
<Badge tone="success">ok</Badge>
<Badge tone="danger">fail</Badge>
<Badge tone="neutral">not configured</Badge>
```

No pulse on any badge in this module.

### Empty state

Used when `vendor_smoke_log` has no rows (smoke has never run):

```tsx
<EmptyState
  illustration={<ShieldCheck className="size-8" aria-hidden />}
  title="No smoke results yet"
  body="Run the smoke check to see per-vendor integration health."
  cta={<RunSmokeButton />}
/>
```

### Error state (data fetch failure)

```tsx
<Card variant="flat" padding="md">
  <p role="alert" className="text-sm text-[var(--color-danger)]">
    Could not load smoke results. Try refreshing — if the problem persists,
    check Supabase connectivity.
  </p>
</Card>
```

### Toast feedback

Uses `useToast()` hook (existing). Two toast cases:

- Smoke triggered: `toast('Smoke check running — results will update in a few seconds.', 'info')`
- Smoke trigger failed: `toast('Could not trigger smoke check. Check staff permissions and Fn health.', 'error')`

## Accessibility Contract

All requirements from `CLAUDE.md` accessibility conventions apply.

| Element | Requirement | Implementation |
|---|---|---|
| "Run smoke now" button | `aria-label` not needed (has visible text); `aria-busy="true"` during load | `loading` prop on `<Button>` already sets `aria-busy` |
| "Running…" loading state | `role="status"` on button or adjacent live region | `<Button loading role="status">Running…</Button>` |
| Status badges | Sufficient contrast: success-soft bg + success text, danger-soft + danger, neutral bg + text-secondary | Existing `Badge` tones all pass WCAG AA; confirmed in prior phases |
| Table | `<table>`, `<thead>`, `<th scope="col">`, `<tbody>` | Exact structure from `AdminAffiliatesReviewQueue` |
| Table keyboard navigation | `tabIndex={0}` on each `<tr>` in tbody; focus-visible ring via Tailwind | `focus-visible:ring-2 focus-visible:ring-[var(--color-primary)]` |
| Error state | `role="alert"` on error paragraph | Per `BaaChainTable` precedent |
| Loading state (data) | Inline `<p className="text-sm text-[var(--color-text-secondary)]">Loading…</p>` | No separate spinner component needed |
| Icon-only controls | None in this module — all controls have visible labels | n/a |
| Page `<h1>` | Present and unique | "Vendor health" heading in `<header>` |
| Section heading | `CardHeader title="Vendor integrations"` renders `<h2>` | Per existing `CardHeader` implementation |
| `prefers-reduced-motion` | No animations in this module (no countUp, no Sparkline) | No action needed |

## States to Implement

| State | Trigger | Render |
|---|---|---|
| Loading | Initial data fetch | `<p className="text-sm text-[--color-text-secondary]">Loading…</p>` inside Card body |
| Empty | `vendor_smoke_log` has zero rows | `<EmptyState>` with inline CTA |
| Populated | Rows present | Full `<table>` |
| Error | Supabase fetch fails | `role="alert"` error paragraph inside `Card variant="flat"` |
| Smoke running | Button clicked, Fn in flight | Button `loading` + Toast info |
| Smoke done | Fn returns | Toast dismisses automatically; table re-fetches |
| Smoke error | Fn invocation fails | Toast error |
| Not authorized | `is_staff()` returns false | `<NotAuthorizedCard />` from AdminShell (verbatim reuse) |
