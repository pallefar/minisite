<objective>
Ship the approved-chunk embedding pipeline + retrieval Edge Function. Nightly cron embeds newly-approved chunks via OpenAI text-embedding-3-small (Vercel AI Gateway). Retrieval endpoint accepts query text, computes embedding, runs HNSW ANN search against external_kb_embeddings, applies freshness-window de-ranking + tier-boost reweighting, returns top-K with metadata. Foundation for Plan 50-08 user-facing surfaces.

Purpose: without this Edge Fn, approved chunks are dead data. UI in Plan 50-08 needs a /rag-retrieve endpoint to query. Cron makes it self-sustaining without manual re-embed triggers.
Output: 2 Edge Fns (4 files) + 1 cron migration + 2 vitest + 1 Deno integration test.
</objective>

      3. SELECT query with cosine distance and JOIN to fetch chunk metadata. Bind parameters in order: `queryEmbedding`, `filters.topic_tag ?? null`, `filters.source_tier ?? null`, `k`. No `drug_id` filter at v1.3 — defer per-drug filtering to Phase 38 ship.
      4. `const ranked = rankAndTrim(rows, k);`
      5. `await logVendorCost(client, {vendor:'openai_embed', amountUsd: 0.020 / 1_000_000 * queryEmbedding.length, action:'retrieve_query'});` (~$0.00001 per query).
      6. Return JSON `{ results: ranked, count: ranked.length }`.
