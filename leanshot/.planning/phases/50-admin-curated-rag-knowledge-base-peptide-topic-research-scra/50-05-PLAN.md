<objective>
Ship the Anthropic-backed summarizer + sentence-aware chunker Edge Function. Takes a raw `rag_chunks` row (source_text_excerpt populated, summary NULL), generates a 2-sentence summary + JSON array of verbatim quote_blocks for medical claims (dosage / indication / contraindication / adverse-event) per D-17 quote-only mode, and updates the row. Honors D-05 language-preservation rule for medical-claim verbatim text + glosses. Hardens against prompt injection from scraped content.

Purpose: without summarization, raw markdown excerpts are useless for retrieval — embeddings are computed from `summary + quote_blocks`. Plan 50-07 reads `summary` to compute embeddings; Plan 50-06 admin queue renders side-by-side source-text vs extracted-quote pane (per UI-SPEC §A3). This Edge Fn is the bridge.
Output: 1 Edge Fn (4 files) + 3 test suites.
</objective>
