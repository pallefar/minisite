# Phase 50 — UI Design Contract

> Visual and interaction contract for the Admin-Curated RAG Knowledge Base. Generated by gsd-ui-researcher, verified by gsd-ui-checker. Bakes in the 36 locked decisions from `50-CONTEXT.md` and inherits the LeanShot design system bundle at `.planning/design-system/project/colors_and_type.css`.

> **Source-of-truth for tokens:** This phase does NOT introduce new color, type, or spacing primitives. It composes the existing `src/index.css` `@theme` tokens (Tailwind v4 CSS-first config) plus the `Card`, `Badge`, `Pill`, `Button`, `Modal`, `Sheet`, `EmptyState`, `Skeleton`, `Toast` primitives in `src/components/ui/`. Any divergence is called out explicitly per surface.

> **Three surface families covered:**
> - **A. Admin** — `/admin/rag/topics`, `/admin/rag/sources`, `/admin/rag/queue`, `/admin/rag/telemetry`, `/admin/rag/cost`
> - **B. End-user in-app** — AI Coach citations (in `AIChatPanel.tsx`), Dashboard `TipOfTheDayCard.tsx`
> - **C. End-user out-of-app (stretch wave)** — Research newsletter email template, public `/research` Research Hub

## Design System

| Property | Value |
|----------|-------|
| Tool | none (Tailwind v4 `@theme` CSS-first, NOT shadcn) |
| Preset | not applicable — LeanShot custom system per `.planning/design-system/project/colors_and_type.css` |
| Component library | none (custom primitives in `src/components/ui/*`) |
| Icon library | `lucide-react ^0.460.0` (existing) |
| Font | Geist (sans), Geist Mono (numerals/IDs), Fraunces italic (editorial accents only) |

**Why no shadcn:** Project locked to React 19 + Tailwind v4 beta + custom Card/Badge/Pill/Modal/Sheet primitives since v1. shadcn would duplicate every primitive and conflict with the `@theme` CSS-variable system. Established by `[[reference_claude_design_bundle_landmines]]` rollout in Phase 13.

## Spacing Scale

Tailwind v4 default `spacing` scale (0.25rem step = 4px multiples). All multiples of 4. NO arbitrary px values permitted in component classNames except the documented exceptions below.

| Token | Tailwind class | Value | Usage in Phase 50 |
|-------|----------------|-------|-------------------|
| xs | `gap-1`, `p-1` | 4px | Icon-to-label gap in Tier badge, footnote marker padding |
| sm | `gap-2`, `p-2` | 8px | Compact filter pill spacing, Badge internal padding |
| md | `gap-4`, `p-4` | 16px | Default card content padding, table row vertical padding |
| lg | `gap-6`, `p-6` | 24px | Card-to-card gap in bento grid, Modal body padding |
| xl | `gap-8`, `p-8` | 32px | Admin section block separators, dashboard page Y-padding |
| 2xl | `gap-12`, `p-12` | 48px | Research Hub article-list vertical rhythm |
| 3xl | `gap-16` | 64px | Research Hub hero → list separation (desktop only) |

**Exceptions (declared up-front to pre-empt UI-checker dimension trap `[[reference_ui_checker_dimension_traps]]`):**
- Footnote superscript marker `[1]` in coach text: inline-flex 14px square hit area (uses `text-[11px]` per existing Badge metric — not a spacing exception).
- Side-by-side source-text/quote layout in queue: `min-h-[420px]` for the comparison pane so short chunks still render two-column readably.
- All other component dimensions inherit from existing `Card` (`rounded-card` = `1.5rem`), `Pill`, `Badge`.

## Typography

**Hard cap: ≤4 font sizes per surface.** Pre-emptive collapse to satisfy gsd-ui-checker dimension trap `[[reference_ui_checker_dimension_traps]]`.

Per-surface inventory (4 sizes max per column):

| Role | Token (CSS var) | Px | Weight | Line height | Admin surfaces | TipOfDay | Coach citation card | Research Hub |
|------|-----------------|----|--------|-------------|----------------|----------|---------------------|--------------|
| Display (page heading) | `--text-2xl` | 28 | 700 | 1.25 | yes | — | — | yes |
| Body (default) | `--text-base` | 16 | 400 | 1.55 | yes | yes | yes | yes |
| Label/eyebrow | `--text-micro` | 12 | 600 (uppercase, tracking 0.06em) | 1 | yes | yes | yes | yes |
| Caption (meta — "as of YYYY-MM-DD", counts) | `--text-xs` | 13 | 500 | 1.45 | yes | yes | yes | yes |

**Footnote marker** (`[1]` in coach answer text): rendered as a `Badge` with `text-[11px]` (already the Badge baseline). Not a new size — reuses existing Badge typography.

**Fraunces italic** (display font) is RESERVED for:
- Research Hub article-page H1 only ("editorial moment" per design system intent).
- NOT used in any admin surface, NOT in Coach, NOT in TipOfDay.

## Color

Locked semantic tokens from `src/index.css` `@theme`. Phase 50 does NOT introduce new color primitives. 60/30/10 split:

| Role | Token | Light value | Usage |
|------|-------|-------------|-------|
| Dominant (60%) | `--color-bg` | `#f2ede0` (cream-100) | Page backgrounds — admin shell, dashboard, Research Hub |
| Secondary (30%) | `--color-surface` / `--color-surface-elevated` | `#fefcf7` / `#f4efe2` | Cards, tables, sidebar, side-by-side review panes |
| Accent (10%) | `--color-primary` | `#1b4842` (teal-700) | See reserved-for list below |
| Destructive | `--color-danger` | `#cb4f4f` (clay) | Reject button, retract action, cost-cap 100% indicator |

**Accent (teal-700) reserved EXCLUSIVELY for:**
1. Primary CTA buttons (e.g., "Approve", "Add topic", "Save changes").
2. Tier-A badge background (highest trust visual signal).
3. Footnote markers `[1]` `[2]` in coach text (link-affordance signal).
4. "Tip of the day" eyebrow label + "Open source" link in citation card.
5. Active tab/route indicator in `/admin/rag/*` sidebar.

**Accent NEVER applied to:** body text, table rows, secondary buttons, filter pills (use neutral surface), all-purpose hover states.

**Tier badge color contract (concrete, locked):**

| Tier | Background | Text | Shape | Copy |
|------|-----------|------|-------|------|
| A (FDA/PubMed) | `--color-primary-soft` (`#dceae5`) | `--color-primary` (`#1b4842`) | `rounded-pill` (reuses Badge) | `Tier A` |
| B (drugs.com, Examine.com) | `--color-info-soft` (same as primary-soft — accepted alias) | `--color-info` | `rounded-pill` | `Tier B` |
| C (lay press, blogs) | `--color-surface-elevated` (`#f4efe2`) + `border-[var(--color-border-strong)]` | `--color-text-secondary` | `rounded-pill` border-variant | `Tier C` |

Implemented as a thin wrapper around existing `Badge`: `<TierBadge tier="A" />` → `<Badge tone="info">Tier A</Badge>` for A/B; Tier C uses `tone="neutral"` (already has border). No new `BadgeTone` value needed.

**Per-source health badge contract:**

| State | Badge tone | Copy + pulse | Source |
|-------|-----------|--------------|--------|
| ok | `success` | `Healthy` (no pulse) | reuses existing `Badge` |
| paused | `warning` | `Paused: {reason}` (no pulse) | reuses existing `Badge` |
| failing | `danger` | `Failing` (pulse=true) | reuses existing `Badge` |

**Cost-cap indicator (0–100% MTD spend bar):**

| Threshold | Color | Microcopy |
|-----------|-------|-----------|
| 0–79% | `--color-success` | `$X.XX of $Y.YY MTD` |
| 80–99% | `--color-warning` | `Warning: 80% of budget consumed` |
| 100% | `--color-danger` | `Auto-paused — admin must acknowledge to resume` |

Uses an inline `<div>` progress bar (4px tall, `rounded-pill`, background `--color-surface-elevated`, fill colored per threshold). No new component primitive; styled inline.

**Reject-reason taxonomy chips** (queue UI):
All reject reasons render as `Pill` (existing primitive) with `tone` mapped:
- `off-topic`, `low-quality`, `duplicate` → neutral
- `factually-wrong`, `off-label`, `safety-concern` → `danger` (subtle, soft variant)

## Layout — Per-Surface Contracts

### A1. `/admin/rag/topics` — Topic CRUD list

- **Container:** `Card` `span={12}` inside Phase 24 admin shell `<main>` (max-w-screen-xl, p-6 lg:p-8).
- **Header row:** Display heading `Topics` + counter `({N})` + right-aligned primary CTA `Add topic`.
- **Filter bar:** Single row of `Pill` filters: `All`, `Curated`, `Open-web`, `By cadence` (dropdown), `Tag` (multi-select dropdown). Search input (existing `Input`) right-aligned, placeholder `Filter by query or tag…`.
- **Density:** **Table** (not card list). Justification: 6 numeric telemetry columns per row need vertical alignment — `font-mono` tabular-nums makes a table the right primitive. Row click opens topic detail in a `Sheet` (right-side, existing primitive).
- **Columns:** `Topic query` (truncated, max-w-prose) · `Tag` (Pill) · `Mode` (Pill: curated/open-web) · `Cadence` (text) · `Docs` (count) · `RAG hits 7d` (count) · `Last scraped` (relative time) · Actions (kebab menu).
- **Empty state:** `EmptyState` primitive — illustration: `lucide-react Database` icon (48px, accent color). Heading: `No topics yet`. Body: `Add the first topic to seed your research pipeline. Suggested starters: GLP-1 muscle loss, tirzepatide titration, nausea management.` CTA: `Add topic`.
- **Soft-delete UX:** Kebab → `Archive topic`. Confirmation Modal copy in Copywriting Contract.
- **Responsive:** Table collapses to card-list at `<md` breakpoint (per-row stacked label+value); filter bar wraps. NO separate mobile component — same `<table>` element with `md:` modifier classes.

### A2. `/admin/rag/sources` — Source allowlist CRUD

- **Container:** `Card` `span={12}`.
- **Header:** `Sources ({N})` + CTA `Add source`.
- **Density:** Table (same justification as A1).
- **Columns:** `Source name` (linked) · `Domain` · `Trust tier` (TierBadge) · `Health` (health badge — pulse if failing) · `Topics using` (count) · `Rejects 30d` (count, danger-colored if ≥5) · `Last scrape` (relative time) · Actions.
- **Health-pulse intent:** ONLY failing sources pulse. Paused sources are flat warning badge (less visually demanding).
- **Empty state:** `EmptyState` — illustration: `lucide-react Globe` (48px). Heading: `No sources allowed yet`. Body: `Seed your allowlist with PubMed, FDA drug labels, drugs.com, and Examine.com — covers ~80% of clinical research surface.` CTA: `Add source`.

### A3. `/admin/rag/queue` — Review queue (HIGHEST UX SCRUTINY)

**This is the highest-density admin surface. Quote-only-mode per D-17 mandates side-by-side as first-class.**

- **Container:** Full-width main pane (no Card wrapper — chrome-free for max review surface).
- **Header:** Display heading `Review queue` + filter pills: `All`, `Tier B`, `Tier C`, by tag, by source. Right-aligned: `Backlog: {N} items` indicator (turns warning at >100 per D-18).
- **Layout — desktop (≥lg):** Two-column grid. Left column (12-col span 7): chunk list (vertical scroll, sticky header). Right column (span 5): chunk detail pane (sticky, vh-aware) with side-by-side source-text vs extracted-quote.
- **Layout — tablet/mobile (<lg):** Single-column. Chunk list visible; tapping a chunk opens detail in a full-height `Sheet` from the bottom.
- **Chunk list item:** Card-like row (uses `Card` primitive with `variant="interactive"`, `span={12}`). Shows: source name + TierBadge + topic tag Pill + 1-line summary (truncated) + "queued {relative-time}" + per-row "Approve" Button (size="sm") and `IconButton` for reject (opens reason dropdown).
- **Detail pane (right column or Sheet):**
  - **Header strip:** Source name (linked external) · TierBadge · "Scraped {date}" · canonical URL link.
  - **Side-by-side block (FIRST-CLASS):**
    - Left half (label: `SOURCE TEXT`, uppercase eyebrow): rendered markdown via `react-markdown` + `dompurify`. Max-height with internal scroll. Background `--color-surface-soft` to differentiate from quote pane.
    - Right half (label: `EXTRACTED QUOTE`, uppercase eyebrow, accent color): the verbatim quote(s) the summarizer pulled for medical claims. Highlighted in source-text pane via `<mark>` (yellow/amber bg). Each quote shows: the quote text + extracted facts (dose / indication / contraindication / adverse-event tag).
    - At `<lg`, the two halves stack vertically (`SOURCE TEXT` on top, `EXTRACTED QUOTE` below).
  - **Summary block** (general narrative, paraphrased): below the side-by-side, full-width.
  - **Action row (sticky bottom):** `Reject` (Button variant=secondary, opens reason dropdown) · `Edit` (Button variant=ghost, opens inline editor in a Modal) · `Approve` (Button variant=primary). Keyboard shortcuts shown as `<kbd>` chips: `A` approve, `R` reject, `E` edit, `J/K` next/prev.
- **Reject reason dropdown:** Pop-over Sheet with 6 Pill options (taxonomy from D-16): `off-topic`, `factually-wrong`, `off-label`, `low-quality`, `duplicate`, `safety-concern`. Tap a Pill = single-click reject. Two danger-colored: `factually-wrong`, `off-label`, `safety-concern`.
- **Empty state:** `EmptyState` — illustration: `lucide-react CheckCheck` (48px, success color). Heading: `Queue clear`. Body: `Nothing to review. Tier-A chunks auto-publish; we'll alert you when Tier B/C items arrive.` No CTA.
- **Loading state:** `Skeleton` row stack (5 rows) on initial load. After action: optimistic UI — row removes immediately, toast confirms, undo affordance for 5s.

### A4. `/admin/rag/telemetry` — Per-topic dashboard

- **Container:** Bento grid (existing 12-col `Card` pattern).
- **Top KPI strip:** 4 KPI cards (each `Card span={3}`): `Topics active`, `Docs ingested (all-time)`, `RAG hits 7d`, `Avg queue age`. Each card: tiny eyebrow label + large mono number (`text-2xl font-mono tabular-nums`) + delta vs last 7d (`text-xs`).
- **Per-topic table:** `Card span={12}`. Columns: topic + tag + docs + RAG hits 7d + tip impressions 7d + tip clicks 7d + newsletter inclusions 7d + source-tier mix (3-bar inline visualization, 100% stacked: A/B/C teal/info-soft/neutral).
- **Empty state per cell:** When a metric is 0, show `—` (em-dash) in text-tertiary, not `0`. Avoids "broken data" perception during seeding.

### A5. `/admin/rag/cost` — Vendor cost dashboard

- **Container:** Bento grid.
- **Top row — 3 vendor cards (`Card span={4}` each):** Firecrawl · OpenAI embeddings · Anthropic summaries. Each card shows:
  - Eyebrow label (vendor name)
  - Large mono spend `$XX.XX` (text-2xl)
  - Caption: `of $YYY.YY budget · {N}% used`
  - Progress bar (4px, colored per threshold from Color section)
  - Below bar: tiny line `Resets {N} days`
- **Per-topic breakdown:** `Card span={12}` table — Topic · Firecrawl spend · OpenAI spend · Anthropic spend · Total. Sortable by Total desc.
- **Trend chart:** `Card span={12}` — **bar chart** (not line). Justification: 30-day daily spend is naturally discrete (per-day buckets); bars communicate "this day cost $X" more clearly than a line, and avoids implying continuous interpolation. Existing `BaseChart.tsx` Chart.js wrapper.
- **Auto-paused banner:** When any vendor hits 100%, full-width banner at top of page (above bento): `--color-danger-soft` background, `lucide-react AlertOctagon` icon, copy: `Scrapers auto-paused — Firecrawl budget exhausted. Acknowledge to resume.` CTA `Acknowledge and resume` (danger Button).
- **Empty state:** First-run only, shows `$0.00 of $YYY.YY` with caption `No spend yet — scrapers run on cadence.`

### B1. AI Coach citation rendering (in `src/components/dashboard/ai/AIChatPanel.tsx`)

- **Inline marker:** Tap-target `<button>` rendered inside markdown text as `<sup>`-like badge: `text-[11px]` accent-colored, `rounded-full` 14px hit area, content = `[N]`. Uses `Badge` primitive with `tone="info"` and `as="button"` adapter.
- **Expansion behavior:** Tap/click opens a **Popover-style** floating card anchored to the marker (desktop) OR a bottom `Sheet` (mobile <md). Card content:
  - Source title (linked, `text-base` semibold)
  - TierBadge inline-right
  - 1-line summary (`text-sm`, 2-line clamp via `line-clamp-2`)
  - `As of YYYY-MM-DD` (eyebrow + date in mono, tabular)
  - `Open source ↗` (link Button variant=ghost, accent color, external-link icon)
  - Disclaimer microcopy (smaller, `text-xs text-tertiary`): `Not medical advice — consult your clinician.`
- **Multiple citations:** When the coach answer cites multiple sources, all `[N]` markers in one paragraph are clickable; the popover supports `prev/next` keyboard nav.
- **Server-side telemetry:** Tap fires `rag_citation_clicked` via PostHog server-side capture (per D-34) — done in the click handler, not in React component lifecycle.

### B2. `TipOfTheDayCard.tsx` (dashboard bento)

- **Span:** `span={6}` on desktop, full-width on mobile. **Justification for span=6 (not 4):** the tip body needs ~2 lines of prose + source/disclaimer block (4 lines total); span=4 cramps the text at lg breakpoint to <30ch width. span=7+ would crowd the row neighbor (`HeroCard`). span=6 leaves room for a sibling KPI tile.
- **Structure (top-to-bottom):**
  1. Eyebrow: `TIP OF THE DAY · {topic-tag pill}` (accent + neutral pill)
  2. Headline: 1-sentence framing, `text-base font-semibold`, 2-line clamp.
  3. Body: 2-sentence excerpt, `text-base text-secondary`, 3-line clamp.
  4. Footer strip (flex-between):
     - Left: `{Source name} · As of {YYYY-MM-DD} · TierBadge`
     - Right: `Open source ↗` (ghost link Button)
  5. Bottom disclaimer (`text-xs text-tertiary`): `Not medical advice — consult your clinician.`
- **Refresh:** Card rotates daily at user's local midnight (computed client-side from store). User can tap a `RotateCcw` IconButton (top-right corner) to manually re-roll within the day's eligible chunks.
- **Empty state (no eligible chunks for user's drug+themes):** Substitute generic Tier-A chunk for the user's drug; if none, hide the card entirely (don't show empty state — bento should not have placeholder cards).
- **Skeleton state:** While fetching, `Skeleton` lines mimicking the 4-line structure.

### C1. Research newsletter email template (stretch)

- **Delivery:** Resend via Phase 25 `email-router` (`phi:false` consumer path).
- **Format:** Single-column, max-width 600px (industry standard email-safe).
- **Color:** Light theme ONLY at v1.3. Dark-mode email handling DEFERRED to v1.4 (most clients still mishandle `prefers-color-scheme` in HTML email; per `[[reference_supabase_auth_traps]]` the cost/benefit doesn't justify v1 work). Background `#f2ede0` (cream-100), surface `#fefcf7`.
- **Typography:** Geist via Google Fonts `<link>` in `<head>` (per design-bundle font-loading note); fallback `Arial, sans-serif`. Sizes: 24px H1, 18px section H2, 16px body, 12px footer. ≤4 sizes.
- **Structure (top-to-bottom):**
  1. Header: LeanShot wordmark (left, 24px), date (right, 12px tertiary).
  2. Greeting: `Hi {first_name},` + 1-line intro from research-desk voice.
  3. **Per-tag sections** (1 H2 per followed tag): `## {Tag name}` + 2–3 items.
     - Each item: source name (linked) · TierBadge (rendered as colored Pill since some clients strip svg) · 1-line summary · `Read at {source} ↗` button (32px tall, accent bg).
     - Standard attribution string in caption row: `{source} · As of {YYYY-MM-DD} · Tier {A|B|C} · Not medical advice` (uses shared i18n key per D-33).
  4. Footer: `Manage preferences` link + **1-click unsubscribe** (reuses Phase 49 `unsubscribe-1click` Edge Fn).
- **Empty state (no new approved chunks for user's tags in past week):** SKIP sending entirely (no "we have nothing for you" email).

### C2. Public `/research` Research Hub page (stretch)

- **Reuses Phase 15 page-builder primitives** (per D-27). New content type: `research-article`.
- **List view layout:** Hero strip (Fraunces italic page H1 `Research` — the only Fraunces moment on this page) + filter Pill row (by tag, by tier) + article list.
- **Article list-item card:** Reuses existing `Card variant="interactive" span={6}`. NOT a new `Article` variant — keeps to ≤4 size constraint and matches dashboard rhythm. Contains:
  - TierBadge (top-right corner)
  - Topic tag Pill (top-left)
  - Headline (`text-base font-semibold`, 2-line clamp)
  - 2-line summary excerpt
  - Footer: `{source} · As of {YYYY-MM-DD}` + `Read at source ↗`
- **Detail view:** `react-markdown` rendered chunk with sanitization, canonical `<link rel="canonical" href="{source_url}">` in `<head>`, JSON-LD `Article` schema (per D-27), persistent disclaimer banner at top + bottom, "Open at source ↗" CTA pinned in sticky right rail (desktop) or bottom (mobile).
- **SEO meta per article:** `og:type=article`, `article:published_time`, `article:modified_time` (from chunk re-validation per D-19), `article:tag=topic_tag`.
- **Empty state (filtered to zero results):** `EmptyState` — `No research matches that filter. Clear filters to see all.` CTA: `Clear filters`.

## Interaction Contract

| Interaction | Behavior |
|-------------|----------|
| Approve chunk (queue) | Optimistic UI — row removes immediately, `Toast` confirms (`Approved · undo`), 5s undo affordance via toast action. |
| Reject chunk | Same optimistic pattern + reason logged to telemetry. |

## Accessibility Contract

- **All icon-only buttons require `aria-label`** (enforced by existing `IconButtonProps` type).
- **Citation popover:** `role="dialog"` + `aria-modal="true"` + focus trap + return-focus to triggering marker on close.
- **TierBadge:** wrapped in `<span aria-label="Tier A source (highest trust)">Tier A</span>` so screen readers announce trust context.
- **Health badge "Failing" pulse:** pulse is decorative; the badge text alone is sufficient accessible signal (`aria-hidden` on the pulse `<span>`).
- **Cost-cap progress bar:** rendered as `<div role="progressbar" aria-valuenow="X" aria-valuemin="0" aria-valuemax="100" aria-label="Firecrawl monthly budget consumed">`.
- **Queue keyboard shortcuts:** documented via `<kbd>` chips in the action row; full list shown in a `?` modal (`Modal` primitive) triggered by `Shift+?`.
- **Reject reason Pills:** `role="radiogroup"` semantics; arrow keys cycle between options.
- **Side-by-side review pane:** at `<lg` breakpoint, stacks vertically; reading order matches DOM order (source-text → extracted quote → summary).
- **Reduced motion:** TipOfDay cross-fade, Sheet/Modal transitions all gate on `useReducedMotion()` hook (existing pattern).
- **Color contrast:** all token combinations from `colors_and_type.css` are pre-verified WCAG AA per design system. Tier C badge (text-secondary on surface-elevated) hits 4.7:1.

## Pre-emptive UI-Checker Trap Mitigations

Per `[[reference_ui_checker_dimension_traps]]`:

| Trap | Pre-emption |
|------|-------------|
| >4 font sizes per surface | Each surface declared ≤4 sizes in Typography section; footnote marker reuses Badge baseline (not new size). |
| Non-standard spacing | Only Tailwind defaults (multiples of 4); the 2 exceptions (`min-h-[420px]` queue pane, `text-[11px]` footnote) are documented and inherit from existing primitives. |
| Responsive as separate variant components | All responsive declared as `sm:`/`md:`/`lg:` modifier prefixes on a single component (e.g., queue layout is one component with `lg:grid-cols-[7fr_5fr]` not separate `<DesktopQueue>` / `<MobileQueue>`). |
| Accent-color overuse | Accent reserved-for list is explicit and bounded (5 use sites); destructive separate; everything else neutral. |
| New primitives without justification | Zero new primitives added; all new components compose existing ones. |
