# Phase 3 — UI Design Contract

> Visual and interaction contract for the pharmacology + insights hardening phase. Scope is narrow by design: uncertainty-band rendering on `MedLevelChart`, Y-axis relabel, watermark text replacement (Phase 2 plugin), and the `DoctorReport` PDF disclaimer. The pharmacology engine versioning (`pkEngineVersion`) and insights refusal-list regex have no user-visible surface and are intentionally outside this contract.

## Color

Phase 3 introduces **no new color tokens**. The uncertainty band uses existing theme variables, resolved live via `getChartTokens()`:

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--color-bg` (`#efebe0` light / `#0b1413` dark) | Page background — unchanged |
| Secondary (30%) | `--color-surface` / `--color-surface-elevated` | Card, modal, chart container surfaces — unchanged |
| Accent (10%) — chart line | `--color-primary` (teal-700 light / teal-300 dark) for past data; `--color-rose` (`#f2a893`) for projected data | Mean curve — unchanged from Phase 2 |
| Uncertainty band fill (NEW use of existing token) | `--color-primary` at **α=0.12** (past) / `--color-rose` at **α=0.12** (projected) | Chart.js `fill: '+1'` between upper and lower bound datasets — `MedLevelChart.tsx` band layer |
| Uncertainty band stroke | none (`borderWidth: 0`, `pointRadius: 0` on the bound datasets) | Bounds are invisible scaffolding; only the fill is visible |
| Watermark text | `rgba(60, 60, 60, 0.12)` light / `rgba(220, 220, 220, 0.18)` dark | Unchanged from Phase 2's plugin options |
| Destructive | `--color-danger` (`#cf5454`) | Not used in this phase — no destructive actions introduced |

**Accent reserved for (Phase 3 specifically):**
1. The past-data mean curve stroke (existing `t.primary`)
2. The projected-data mean curve stroke (existing `t.rose`)
3. The uncertainty band fill (12% alpha of the same two colors — same hue family, NOT a new accent)

**Contrast rules:**
- The band's 12% alpha must not visually swallow the mean line — the line's `borderWidth: 2.4` is preserved so the mean curve stays visually dominant against the band.
- The watermark opacity (`0.12` light / `0.18` dark) must stay readable but never compete with the data — preserve the Phase 2 values; do not crank.

**Forbidden in this phase:**
- No `ng/mL`, `pmol/L`, or any measurement-grade unit anywhere on the chart canvas or in the PDF (SC#1 + PK-04). The Y-axis carries the abstract label `Estimate · arbitrary units` only.
- No second semantic color introduced. No "warning yellow" band, no "danger red" band — uncertainty is a styling state, not a severity state.

### Punctuation rules

- **Em-dash** in the watermark string is U+2014 (—), not a hyphen-minus (-) or en-dash (–). The Phase 2 implementation already enforces this (`medLevelWatermarkPlugin.ts:17`); Phase 3 preserves the same character class — verified by the existing em-dash byte-verification check (CONTEXT D-09).
- **Middle dot** `·` (U+00B7) in `Estimate · ~30% inter-individual variation` and `Estimate · arbitrary units` is U+00B7, NOT a bullet (•) or interpunct variants.
- **Tilde** `~` in `~30%` is ASCII U+007E.
- **Lowercase `estimate`** at the start of the watermark string is intentional — preserved verbatim from CONTEXT D-08. Do NOT title-case.

### Forbidden phrases (insights refusal-list — visible-string view)

Even though the refusal-list regex itself is non-visual, the user-visible *consequence* is that `generateInsights` output never produces any of the following stems in dose-change context (per CONTEXT D-05): `increase`, `decrease`, `raise`, `lower`, `double`, `halve`, `skip`, `stop`, `start`, `taper`, `ramp`, `escalate`, `de-escalate`, `bump`, `more`, `less` — when within 5 tokens of `dose`, `mg`, `unit`, `injection`, or a brand/INN medication name. Insights copy authors (planner + implementer) MUST avoid these constructions when drafting any rule-based insight string Phase 3 introduces or modifies.

## Interaction Contract

Phase 3 introduces **no new interactions**. The chart remains static-display only — no hover tooltip changes, no click handlers added, no keyboard shortcuts. The uncertainty band is purely visual.

| Surface | Phase 3 behavior |
|---------|------------------|
| `MedLevelChart` hover tooltip | Continues to show the mean value at the hovered x-index via existing Chart.js `interaction: { mode: 'index' }`. | Reduced motion | No new animations introduced. The band paints once on mount via Chart.js's standard render; no Framer Motion transitions. |
| Print / PDF (`DoctorReport`) | The chart-overlay watermark survives print (existing Phase 2 behavior). The new PDF footer paragraph is added in DOM (printable) at the same level as the existing italic disclaimer block — verified to appear in `window.print()` output (D-10 path: footer-style disclaimer string; canvas is not directly rendered into the PDF in current `DoctorReport`). |

## Layout Contract (chart anatomy)

The uncertainty band changes the **internal composition** of `MedLevelChart`'s Chart.js config, but not its outer box. The component's container, height (`280px` default), and surrounding card chrome (`GLPCurveCard`, `MedicationTab`) are unchanged.

Chart.js dataset order (z-order, bottom to top):
1. Past upper bound (invisible stroke, fill to "+1" target = past lower bound) — band area
2. Past lower bound (invisible stroke) — band boundary
3. Projected upper bound (invisible stroke, fill to "+1" = projected lower bound) — band area
4. Projected lower bound (invisible stroke)
5. Past mean line (visible — existing `t.primary` 2.4px stroke)
6. Projected mean line (visible — existing `t.rose` 2.4px stroke, dashed)
7. **Watermark plugin** in `afterDraw` (existing — paints last, on top of everything)

**Critical constraint (existing, preserved):** The watermark plugin paints in `afterDraw`, the band fills in `beforeDraw`-equivalent (datasets render before plugins). This ordering is documented at `medLevelWatermarkPlugin.ts:9-11` — Phase 3 MUST NOT change plugin hook order.

## Accessibility Contract (Phase 3 increment)

- **Color-only conveyance:** the band's information ("there is uncertainty around the mean") MUST also be conveyed in text — satisfied by the `Estimate · ~30% inter-individual variation` caption and the watermark string. A color-blind or low-vision user reading the caption gets the same information as a sighted user reading the band.
- **Screen reader:** updated `aria-label` (above) explicitly states "estimate" and "not a measured serum level" so SR users hear the disclaimer without needing to read the canvas-painted watermark (which is inaccessible to AT).
- **Contrast for axis label:** the new `Estimate · arbitrary units` title uses `t.tick` = `--color-chart-tick` (`#66716c` light / `#a8b0ab` dark). Both meet WCAG AA contrast (≥4.5:1) against `--color-surface`.
- **Print legibility:** the new PDF footer paragraph uses the same `text-[11px] text-[var(--color-text-tertiary)] italic` styling as the adjacent existing disclaimer at `DoctorReport.tsx:197` — verified ≥4.5:1 against `--color-surface` in both themes.
