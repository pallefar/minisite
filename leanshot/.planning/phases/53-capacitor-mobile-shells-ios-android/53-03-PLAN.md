## Trust Boundaries

| GitHub Actions → Apple/Play signing | Signing material crosses into gated jobs only when secrets are present |
| Android intent-filter → web origin | App Links bind the app to https://app.leanshot.app, verified against the public assetlinks.json |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-53-07 | Elevation of Privilege | CI signing secrets (Apple cert / Play keystore) | mitigate | Secrets are GitHub Secrets, decoded only inside gated jobs guarded by `if: env.X != ''`; unsigned builds always run without any secret |
| T-53-08 | Spoofing | Android App Links host binding | mitigate | autoVerify intent-filter binds only the exact host app.leanshot.app (no wildcard); verification requires the public assetlinks.json fingerprint match (real SHA256 wired at Phase 70) |
| T-53-09 | Information Disclosure | secrets referenced in `if:` expressions | mitigate | GitHub forbids `secrets.*` in `if:`; this plan maps secrets to job-level `env:` then gates on `env.X != ''` — secret values never appear in workflow conditionals or logs |
| T-53-SC | Tampering | npm/gem installs in CI | accept | CI runs `npm ci --legacy-peer-deps` against the committed lockfile (no new packages); fastlane gem pinned in 53-01 Gemfile; all packages `[Approved]` per RESEARCH audit |
</threat_model>
