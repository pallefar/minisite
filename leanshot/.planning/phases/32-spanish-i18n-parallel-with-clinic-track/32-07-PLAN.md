useHreflangTags hook pattern (mirrors the existing brand-token head injection from Phase 15/31):
```typescript
import { useEffect } from 'react';

export function useHreflangTags(opts: { path?: string } = {}) {
  useEffect(() => {
    const path = opts.path ?? window.location.pathname;
    const base = `${window.location.origin}${path}`;
    const tags: Array<[string, string]> = [
      ['en', base],
      ['es', `${base}?lang=es`],
      ['x-default', base],
    ];
    const created: HTMLLinkElement[] = [];
    for (const [lng, href] of tags) {
      const link = document.createElement('link');
      link.rel = 'alternate';
      link.hreflang = lng;
      link.href = href;
      link.dataset.i18nHreflang = 'true';   // marker for cleanup
      document.head.appendChild(link);
      created.push(link);
    }
    return () => { for (const el of created) el.remove(); };
  }, [opts.path]);
}
```

CSS logical-property mapping:
| Physical | Logical |
|----------|---------|
| margin-left | margin-inline-start |
| margin-right | margin-inline-end |
| padding-left | padding-inline-start |
| padding-right | padding-inline-end |
| text-align: left | text-align: start |
| text-align: right | text-align: end |
| border-left | border-inline-start |
| border-right | border-inline-end |
| left: 0 (positioning) | inset-inline-start: 0 |
| right: 0 (positioning) | inset-inline-end: 0 |
| float: left | float: inline-start |
| float: right | float: inline-end |

Tailwind v4 supports all logical-property utilities natively: `ms-4` (margin-inline-start), `me-4`, `ps-4`, `pe-4`, `text-start`, `text-end`, `border-s`, `border-e`, `start-0`, `end-0`. Use Tailwind utilities first; fall back to inline `style={{ marginInlineStart: ... }}` only for dynamic values.

Whitelist directories for the lint script:
- `src/illustrations/` (decorative SVG; many use `transform` with `translate(-50%, -50%)` which is not physical-property forbidden but adjacent — exclude to avoid false positives)
- `node_modules/`, `dist/`, `*.test.{ts,tsx}` (already excluded by find globs)
- Any third-party widget embed where we don't control the markup

Per `reference_macos_bsd_sed_groups.md`: BSD sed `\(group\)` substitutions silently no-op on macOS. Any in-place migration scripts MUST use `perl -i -pe '...'` for grouped regex replacements, NOT `sed -i.bak 's/...\(A\|B\)/...'`.
