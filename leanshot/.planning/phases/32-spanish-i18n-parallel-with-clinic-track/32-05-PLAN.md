## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Edge Fn invocation → supabase.from('profiles').select | service_role read; bypasses RLS by design (Edge Fns are trusted). |
| Edge Fn → Resend API | service-to-service over HTTPS; RESEND_API_KEY held as Function Secret. |
| renderInLocale interpolation | i18next does NOT auto-escape — escapeValue:false is set because email body is plain text. If any consumer renders the output as HTML, IT must escape user-controlled vars. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-32-05-01 | Information Disclosure | profiles.locale lookup exposes user existence via timing diff | accept | Locale lookup is hot-cached and runs server-side; no public timing oracle. |
| T-32-05-02 | Tampering | locale_overrides admin (Plan 32-04) edits email subject via global override | mitigate | DEFERRED — Edge Fn side of locale_overrides not wired in v1.3 (D-08 says client + edge can reuse the catalog; admin override impact on Edge is async via re-deploy or cold-start eviction). Document as known scope boundary. |
