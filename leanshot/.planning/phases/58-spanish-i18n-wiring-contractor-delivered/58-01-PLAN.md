<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| translation catalog -> rendered UI | ES catalog strings are rendered to patients; a mistranslated clinical string is a patient-harm vector |
| `?lang=` query param -> i18next locale | untrusted URL param selects locale catalog |
| machine-translation tooling -> ES catalogs | translations generated locally by Claude; no patient data sent to an external MT service |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-58-01 | Tampering | ES locale catalogs (interpolation integrity) | mitigate | Gate 3 (Task 1) fails CI when an ES value contains a translated `{{var}}` name, preventing literal-render of dose/unit/count placeholders |
| T-58-02 | Tampering | clinical safety strings (dose/unit/site/contraindication) | mitigate + transfer | Route clinical terms through clinical-glossary.md (Task 3) flagged `signoff-pending`; human clinical-advisor signoff TRANSFERRED to Phase 70 HUMAN-UAT |
| T-58-03 | Information Disclosure | machine-translation pipeline | accept | Translations generated locally by Claude — no PII/PHI sent to an external MT service; no BAA required; acceptable per data-minimization posture |
| T-58-04 | Spoofing | `?lang=` query param | accept | init.ts `supportedLngs: ['en','es']` + `load: 'languageOnly'` clamps unsupported locales to EN fallback; no XSS vector (React JSX escaping; no dangerouslySetInnerHTML in patient surfaces) |
| T-58-SC | Tampering | npm/pip/cargo installs | accept | Phase 58 installs ZERO new packages (RESEARCH Package Legitimacy Audit empty); no install task exists |
</threat_model>
