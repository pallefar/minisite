Operator-runnable script (Deno or Node — match existing scripts/ convention; check `ls scripts/`).

Args: `--org-id <uuid>` (target demo org) + optional `--patient-count <n>` (default 5).

Logic:
1. Verify the target org exists + `is_demo = true` (refuse to seed real orgs)
2. Generate N synthetic patients using deterministic seeds (e.g. `crypto.subtle.digest('SHA-256', org_id + 'patient-' + i)` truncated to a UUID-like string)
3. For each patient:
   - Insert `patients` row with fake-but-plausible name (e.g. "Demo Patient 1" through "Demo Patient 5")
   - Insert `org_memberships` row linking patient → org
   - Seed 60 days of injection-log data (one dose per week, alternating between abdomen sites)
   - Seed 60 days of weight entries (linear weight loss from 220→195 lb)
   - Seed sample mood/symptom logs for the most recent week
4. Output: created patient IDs + their auth_user IDs

Determinism: same input args → same output. Useful for tests + repeat runs.

Refuse to run if `--org-id` doesn't have `is_demo = true` — fail-loud + bail.
