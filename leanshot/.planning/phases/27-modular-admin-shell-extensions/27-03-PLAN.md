New SECDEF RPC contract:

  admin_palette_recent() returns table (
    item_type text,        -- 'member' | 'helpdesk_ticket' | 'affiliate' | 'cohort' | 'audit_log_entry'
    item_id text,           -- the target row id (audit_logs.row_id or target_user_id)
    label text,             -- displayable label (e.g. 'Alice Liddell' or 'Ticket #42')
    route text,             -- the admin route to navigate to (e.g. '/admin/users/<id>')
    last_interacted_at timestamptz
  )
    - raises 'forbidden' (42501) if not is_admin_at_least('admin')
    - returns top 20 distinct (item_type, item_id) rows from audit_logs where user_id = auth.uid()
      and created_at > now() - interval '7 days', ordered by max(created_at) desc
    - SECURITY DEFINER + STABLE; no audit log write (read-only)

New client lib contracts:

  isAal2Fresh(): Promise<boolean>
    Implementation order:
    1. supabase.auth.mfa.getAuthenticatorAssuranceLevel() — fail-closed if !== 'aal2'
    2. supabase.auth.getSession() → decode JWT payload
    3. If payload.auth_time exists: freshness = (Date.now()/1000 - auth_time) < 900
    4. Else fallback: read localStorage 'leanshot_aal2_last_verified' timestamp
       (set by requireAal2Fresh's challenge handler on successful verify)
    5. Both absent → return false (force re-challenge)

  requireAal2Fresh(onChallenge: () => Promise<{factorId, code}>): Promise<void>
    - if isAal2Fresh() → return immediately
    - else invoke onChallenge() to get TOTP code from UI
    - supabase.auth.mfa.challengeAndVerify({factorId, code})
    - on verify success: localStorage.setItem('leanshot_aal2_last_verified', String(Date.now()))
    - throws Error('aal2_challenge_failed') on verify failure

  PaletteItem = {
    id: string,
    label: string,
    icon?: React.ComponentType<{ size?: number }>,
    group: 'modules' | 'recent' | 'quick_actions',
    destructive?: boolean,
    onSelect: () => void | Promise<void>,
  }

  buildPaletteIndex(
    adminRole: 'staff'|'admin'|'superadmin',
    posthog: { isFeatureEnabled: (k: string) => boolean | undefined },
    recentItems: RecentItem[],
  ): PaletteItem[]
    - Modules group: ADMIN_MODULES.filter(m => hasMinRole(adminRole, m.minRole) && posthog.isFeatureEnabled(m.flagKey) !== false)
    - Recent group: maps recentItems to PaletteItem with onSelect = navigate(item.route)
    - Quick Actions group: static array (defined in quick-actions.ts) with destructive flag set per entry
