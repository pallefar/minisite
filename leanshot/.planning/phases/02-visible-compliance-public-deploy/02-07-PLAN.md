**CSP CORRECTIONS to D-05** (planner-level corrections per orchestrator brief — RESEARCH gotcha #2):

D-05's literal text omits four things that are required for the app to function. The vercel.json CSP MUST include all corrections below:

| What | Why |
|------|-----|
| `https://fonts.googleapis.com` in `style-src` | `index.html:13-16` loads Google Fonts (Inter, Fraunces, JetBrains Mono); without this, fonts fall back to system |
| `https://fonts.gstatic.com` in `font-src` | Same — the actual font files load from gstatic |
| `worker-src 'self' blob:` | PostHog Replay + future web worker patterns silently fail without this |
| `blob:` in `img-src` | `BodyTab` uses `URL.createObjectURL` for photo previews |
| `https://*.ingest.us.sentry.io` + `https://*.ingest.sentry.io` in `connect-src` (NOT `*.sentry.io`) | CSP wildcards are single-label and do NOT cross dots — `*.sentry.io` fails to match `oXXX.ingest.us.sentry.io` (RESEARCH Pitfall 1) |
| `https://*.posthog.com` in `connect-src` | PostHog's official recommendation; covers `us.i.posthog.com` and other subdomains |

The corrected CSP value (single line, no internal whitespace beyond directive separators):
```
default-src 'none'; script-src 'self'; connect-src 'self' https://*.ingest.us.sentry.io https://*.ingest.sentry.io https://*.posthog.com https://api.anthropic.com; style-src 'self' 'unsafe-inline' https://fonts.googleapis.com; img-src 'self' data: blob:; font-src 'self' data: https://fonts.gstatic.com; frame-src 'none'; object-src 'none'; base-uri 'self'; form-action 'self'; worker-src 'self' blob:
```

Document the four corrections inline in `vercel.json` as a `// PLANNER NOTE` comment block at the top — but JSON does not allow comments. Use `.jsonc` style and rely on the `$schema` URL to allow trailing commas / comments in tooling. Vercel's CLI explicitly supports JSONC (line comments + trailing commas in `vercel.json`) [per Context7 /websites/vercel]. If unsure, keep the file strict JSON and put the rationale in `02-07-SUMMARY.md` plus a `vercel.json.notes.md` sibling.

**vite.config.ts — final shape** (assembles 02-02's visualizer + Phase 2's Sentry + manualChunks):

```typescript
import { defineConfig, loadEnv } from 'vitest/config';
import { fileURLToPath, URL } from 'node:url';
import react from '@vitejs/plugin-react';
import tailwindcss from '@tailwindcss/vite';
import { sentryVitePlugin } from '@sentry/vite-plugin';
import { visualizer } from 'rollup-plugin-visualizer';

export default defineConfig(({ mode }) => {
  const env = loadEnv(mode, process.cwd(), '');

  return {
    plugins: [
      react(),
      tailwindcss(),
      process.env.ANALYZE === 'true' &&
        visualizer({
          filename: 'dist/stats.html',
          template: 'treemap',
          gzipSize: true,
          brotliSize: true,
        }),
      // Sentry plugin MUST be last per official guidance.
      // disable: !env.SENTRY_AUTH_TOKEN makes Preview + Development complete no-ops (D-22).
      sentryVitePlugin({
        authToken: env.SENTRY_AUTH_TOKEN,
        org: env.SENTRY_ORG,
        project: env.SENTRY_PROJECT,
        release: { name: process.env.VERCEL_GIT_COMMIT_SHA },
        sourcemaps: { filesToDeleteAfterUpload: ['./dist/**/*.map'] },
        disable: !env.SENTRY_AUTH_TOKEN,
      }),
    ].filter(Boolean),
    resolve: {
      alias: { '@': fileURLToPath(new URL('./src', import.meta.url)) },
    },
    server: { port: 5173, host: true },
    build: {
      // 'hidden' generates .map files but does NOT add the sourceMappingURL comment to .js.
      // Even if a .map slips past filesToDeleteAfterUpload, clients can't fetch it (D-21).
      sourcemap: 'hidden',
      rollupOptions: {
        output: {
          // D-23 — manualChunks per 02-02 measurement (verify against the approved shape).
          manualChunks: {
            'vendor-charts': ['chart.js'],
            'vendor-motion': ['framer-motion'],
            'vendor-icons': ['lucide-react'],
            'vendor-react': ['react', 'react-dom'],
          },
        },
      },
    },
    test: {
      environment: 'jsdom',
      globals: true,
      setupFiles: ['./src/test-setup.ts'],
      include: ['src/**/*.test.{ts,tsx}'],
      exclude: ['e2e/**', 'node_modules/**', 'dist/**'],
      css: false,
    },
  };
});
```

**TypeScript strict-mode caveat**: `defineConfig`'s plugin array signature may complain about the `false`-typed entry from `process.env.ANALYZE === 'true' && visualizer(…)`. Use the same `as PluginOption[]` cast 02-02 added, OR replace the `&&` shortcut with a ternary:
```typescript
process.env.ANALYZE === 'true' ? visualizer({ … }) : null,
```
and rely on `.filter(Boolean)`.
