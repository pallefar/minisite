**Chart.js plugin options shape**:

The `Plugin<'line', TOpts>` generic is the second-arg type for the `afterDraw(chart, args, options)` signature. The `options` come from `config.options.plugins.<pluginId>` (the same `medLevelWatermark` key shown above). At runtime, plugin options live at `chart.config.options.plugins.medLevelWatermark` — Chart.js merges them automatically.

**Theme integration**:

`MedLevelChart.tsx` already imports `getChartTokens(theme)` (line 3 per PATTERNS row 2). Read `src/lib/chart-theme.ts` to confirm the export shape — likely `getChartTokens(theme: 'light' | 'dark') => { tick: string, grid: string, … }`. The watermark plugin receives `color` (RGB triplet string) and `opacity` (number) via `options.plugins.medLevelWatermark`. Theme propagation happens entirely via React's `theme` state passed through `useMemo` dependencies.

**Theme remount caveat** (per RESEARCH §Pattern 4):

Chart.js does NOT re-read `config.plugins` on `.update()` — plugins attach at construction. `BaseChart.tsx` already destroys-and-recreates the chart on theme change (lines 35-44, key=theme pattern). So a theme switch will re-construct the chart with the new plugin options. **No additional code needed** for theme switching.

**Watermark text** (SC#3, RESEARCH "Code Examples"):

```
Estimate — not medical advice
```

The em-dash (U+2014, ` — `) is NOT a hyphen. Some editors auto-correct hyphens to em-dashes; some don't. Write the file in a way that prevents accidental hyphen substitution — use a TypeScript string constant at the top of the plugin file:

```typescript
const WATERMARK_TEXT = 'Estimate — not medical advice'; // U+2014 EM DASH (SC#3 verbatim)
```

The escape sequence guarantees correctness regardless of editor quirks. The plugin test asserts:
```typescript

```

       ```typescript
       /**
        * Chart.js per-instance plugin: diagonal watermark across the drug-level chart.
        *
        * Scope: ONLY MedLevelChart (D-14). Registered via `config.plugins: [medLevelWatermarkPlugin]`
        * on the MedLevelChart instance, NEVER via `Chart.register()` globally (which would
        * leak the watermark onto weight, symptom, and sparkline charts).
        *
        * Renders in `afterDraw` so the watermark is the LAST thing painted onto the canvas
        * (above the data line + legend). Phase 3's uncertainty band will use `beforeDraw`
        * so the band paints UNDER the line; this plugin's draw order is preserved.
        *
        * Text is verbatim per SC#3: 'Estimate — not medical advice' (em-dash U+2014).
        * Escape sequence `—` used to prevent hyphen auto-correction in editors.
        */
       import type { Chart, Plugin } from 'chart.js';

       const WATERMARK_TEXT = 'Estimate — not medical advice'; // U+2014 EM DASH — SC#3 verbatim

       export interface MedLevelWatermarkOptions {
         /** RGB triplet string e.g. '60, 60, 60'. Default: '120, 120, 120'. */
         color?: string;
         /** 0..1. Default 0.12 (light theme); pass 0.18 for dark theme. */
         opacity?: number;
         /** Override text (testing only — production uses the verbatim SC#3 string). */
         text?: string;
         /** Override font family. */
         fontFamily?: string;
       }

       export const medLevelWatermarkPlugin: Plugin<'line', MedLevelWatermarkOptions> = {
         id: 'medLevelWatermark',
         afterDraw(chart: Chart<'line'>, _args, options: MedLevelWatermarkOptions) {
           const { ctx, chartArea } = chart;
           if (!chartArea) return;
           const { left, top, width, height } = chartArea;
           const cx = left + width / 2;
           const cy = top + height / 2;
           const text = options.text ?? WATERMARK_TEXT;
           const opacity = options.opacity ?? 0.12;
           const color = options.color ?? '120, 120, 120';
           const fontFamily = options.fontFamily ?? 'Inter, system-ui, sans-serif';

           ctx.save();
           ctx.translate(cx, cy);
           ctx.rotate(-Math.PI / 4); // 45° counter-clockwise (D-13)
           ctx.font = `bold ${Math.max(14, height * 0.08)}px ${fontFamily}`;
           ctx.textAlign = 'center';
           ctx.textBaseline = 'middle';
           ctx.fillStyle = `rgba(${color}, ${opacity})`;
           ctx.fillText(text, 0, 0);
           ctx.restore();
         },
       };
       ```
