### `.github/workflows/sentry-dsn-check.yml`
Runs on push/PR. Single job:
- Checkout
- Set up Deno (`denoland/setup-deno@v1`)
- Run `deno run -A scripts/ci/check-sentry-imports.ts`
- Fail if exit code != 0

### `scripts/ci/check-sentry-imports.ts`
Script logic:
1. Walk `supabase/functions/*/` for `index.ts` + `handler.ts` files
2. For each file, parse imports for `@sentry/*` references
3. If a Fn imports any `@sentry/*` symbol BUT the imported file resolves to a stub (empty exports or `{}` const), fail with the Fn name
4. Allow-list: Fns explicitly marked as "no Sentry" via header comment `// SENTRY-DISABLED: <reason>`
5. Output: list of Fns with verified-real Sentry imports + list of failures

Test (`check-sentry-imports.test.ts`):
- Stub a temp Fn with real `@sentry/deno` import → passes
- Stub a temp Fn with no-op import → fails
- Stub a Fn with `SENTRY-DISABLED` comment → allowed
- Use Deno test runner; not Vitest

Note: Phase 42 shipped @sentry/capacitor; Edge Fns use @sentry/deno (different package). The check needs to handle both: anything matching `@sentry/.+` import path. If the project doesn't actually use Sentry on Edge Fns yet, the check should report "no Sentry-using Edge Fns found" + exit 0 (informational); fail only if there's a stub being silently used.

const SAMPLES = 10;
const COLD_START_THRESHOLD_MS = 1500;

async function timeColdStart(fn: string) {
  // Hit /healthz with a cold-cache header to force fresh container
  const url = `https://ytnsipxxmzgaebkqmokp.supabase.co/functions/v1/${fn}/healthz`;
  const samples: number[] = [];
  for (let i = 0; i < SAMPLES; i++) {
    const start = performance.now();
    await fetch(url, { headers: { 'cache-control': 'no-cache' } });
    samples.push(performance.now() - start);
    await new Promise(r => setTimeout(r, 60_000)); // 1min between samples — force cold
  }
  samples.sort((a, b) => a - b);
  return {
    p50: samples[Math.floor(SAMPLES * 0.5)],
    p95: samples[Math.floor(SAMPLES * 0.95)],
    p99: samples[SAMPLES - 1],
  };
}
