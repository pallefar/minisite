### `leanshot/playwright.config.vr.ts`
Separate config (NOT main playwright.config.ts) to isolate VR runs from any existing e2e. Projects: `chromium-desktop` (1280×720), `chromium-mobile` (375×667). Two browsers × 2 themes (via `colorScheme` page option) = 4 variants per page.

### `leanshot/tests/vr/v1.4/baseline.spec.ts`
For each v1.4 surface, take + compare screenshot:
- `/settings/security` (Phase 66)
- `/admin/users/security` (Phase 66)
- `/for-doctors`, `/for-clinics`, `/for-coaches` (Phase 68)
- `/admin/tax` (Phase 65)
- `/settings/billing/refund` (Phase 65)

For each:
```ts
test('/for-doctors light desktop', async ({ page }) => {
  await page.emulateMedia({ colorScheme: 'light' });
  await page.goto('/for-doctors');
  await expect(page).toHaveScreenshot('for-doctors-light-desktop.png', { fullPage: true });
});
test('/for-doctors dark desktop', async ({ page }) => {
  await page.emulateMedia({ colorScheme: 'dark' });
  await page.goto('/for-doctors');
  await expect(page).toHaveScreenshot('for-doctors-dark-desktop.png', { fullPage: true });
});
// ... mobile variants
```

Snapshot tolerance: 0.5% pixel diff (default for Playwright VR).
