Heuristic checks:
- Hard-coded `w-[NNNpx]` widths > 375 without `md:` or `lg:` responsive override → flag (375px is the iPhone SE breakpoint)

- `overflow-x-auto` declarations → flag (often indicates horizontal-scroll fallback for content that should reflow)
- Tables without `<div class="overflow-x-auto">` wrapper → flag (small-screen UX)

Output: markdown report. Defer fixes.
