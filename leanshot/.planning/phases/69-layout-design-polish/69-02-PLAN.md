DS primitives in scope (from `leanshot/src/components/ui/`):
- Button, Card, Modal, Sheet, Pill, PillGroup, EmptyState, Input, Toast, Badge, ProgressRing, Skeleton, Sparkline, SwipeToDelete

For each primitive, detect probable duplicates:
- **Button duplicate signal**: `<button>` with `className="..."` matching pattern `bg-primary text-` + `rounded-` + `px-` + `py-` (i.e. styled button outside of `<Button>`)
- **Card duplicate signal**: `<div>` with `className` containing `bg-surface` + `rounded-` + `border-` + `p-` + (any of `shadow-`)
- **Modal duplicate**: `<div role="dialog">` NOT imported from `@/components/ui/Modal`
- **Input duplicate**: `<input>` with custom styling NOT wrapped by `<Input>`

Output: markdown report at `leanshot/.planning/design-system/primitive-adoption-report.md`:
```markdown

- `src/components/X.tsx:42` — styled `<button>` likely should be `<Button variant="primary">`
- ...

## Card — N findings
- ...
```

Exit code 0 always (report-only, NOT fail-gate — Phase 69.5 executes fixes).

Script is heuristic — false positives expected. Operator filters during fix pass.
