  <action>
    Create three SECDEF functions in one migration.

    Function A: `public.update_lesson_position(p_lesson_id uuid, p_last_position_seconds integer, p_max_position_reached_seconds integer)` returns void.
    - SECURITY DEFINER; `set search_path = public, extensions, pg_catalog`.
    - Resolves the calling user via `auth.uid()`; raises `exception 'unauthorized'` if null.
    - Looks up `course_id` from `course_lessons` via JOIN through course_modules (single query).
    - Executes:
      ```
      INSERT INTO public.lesson_progress (user_id, lesson_id, course_id,
        last_position_seconds, max_position_reached_seconds, last_seen_at)
      VALUES (auth.uid(), p_lesson_id, v_course_id,
        p_last_position_seconds, p_max_position_reached_seconds, now())
      ON CONFLICT (user_id, lesson_id) DO UPDATE SET
        last_position_seconds = EXCLUDED.last_position_seconds,
        max_position_reached_seconds = GREATEST(
          public.lesson_progress.max_position_reached_seconds,
          EXCLUDED.max_position_reached_seconds
        ),
        last_seen_at = now();
      ```
    - `GREATEST(...)` is mandatory — scrub-back must NOT regress max_position_reached_seconds (per D-12 + RESEARCH Pattern 7).
    - NO `ON CONFLICT DO DELETE` anywhere.

    Function B: `public.complete_lesson(p_lesson_id uuid)` returns boolean (true if marked complete; false if threshold not met).
    - SECURITY DEFINER; same search_path.
    - Loads (duration_seconds, course_id, enforce_completion) by joining course_lessons → course_modules → courses on p_lesson_id.
    - Loads max_position_reached_seconds from lesson_progress WHERE user_id=auth.uid() AND lesson_id=p_lesson_id; if row missing, return false.
    - If `enforce_completion = true` AND `(max_position_reached_seconds::numeric / NULLIF(duration_seconds,0)) < 0.95`, return false (NO update).
    - Otherwise UPDATE lesson_progress SET completed_at = now() WHERE user_id=auth.uid() AND lesson_id=p_lesson_id; return true.
    - Idempotent: re-calling on an already-completed lesson returns true without changing completed_at.

    Function C: `public.complete_course(p_course_id uuid)` returns table(certificate_id uuid, already_issued boolean).
    - SECURITY DEFINER; same search_path.
    - Counts `required_total` = COUNT(*) FROM course_lessons l JOIN course_modules m ON m.id=l.module_id WHERE m.course_id=p_course_id AND l.is_required=true.
    - Counts `required_completed` = COUNT(*) of the same set JOIN lesson_progress p ON p.lesson_id=l.id AND p.user_id=auth.uid() AND p.completed_at IS NOT NULL.
    - Loads `threshold_pct` from courses; if `(required_completed::numeric / NULLIF(required_total,0) * 100) < threshold_pct` raise `exception 'course_not_complete'`.
    - Checks for existing certificate row (user_id, course_id); if found, RETURN QUERY SELECT id, true; exit.
    - Otherwise INSERT into certificates (id, user_id, course_id, issued_at, version, verification_token):
      - `verification_token` = placeholder text like `'PENDING_'||gen_random_uuid()::text` — the actual HMAC token is computed by `generate-course-certificate` Edge Fn (Plan 46-07) which UPDATEs verification_token after computing HMAC over (cert_id, user_id, course_id, issued_at). The RPC returns the cert_id; the Edge Fn handles HMAC + Storage upload.
    - RETURN QUERY SELECT new_cert_id, false.

    GRANTs:
    - `revoke all on function ... from public; grant execute on function ... to authenticated;` for all 3.

    File header comment block lists all 3 RPCs + their D-XX decision IDs + the threat refs (T-46-02 anti-skip; T-46-07 implicit via service role boundary).
