<!-- Edge Fn HTTP contract -->

POST /functions/v1/notify-community
  Headers: Authorization: Bearer <token>
    token MAY be either:
      (a) SUPABASE_SERVICE_ROLE_KEY  → constantTimeEqual gate; full trust
      (b) A user JWT                 → admin.auth.getUser(bearer).user.id MUST equal
                                       body.mentioned_by_user_id (kind='mention')
                                       OR body.commenter_user_id (kind='reply')

  Body:
    Mention fan-out:
      { kind: 'mention', target_type: 'post' | 'comment', target_id: string,
        space_id: string, mentioned_by_user_id: string, mentioned_by_name: string }
    Reply fan-out:
      { kind: 'reply', post_id: string, comment_id: string, space_id: string,
        commenter_user_id: string, commenter_name: string }

  Responses:
    200 → { fanout_count: number }
    401 → { error: 'unauthorized' }                  // neither auth path succeeded
    403 → { error: 'identity_mismatch' }             // user JWT but body claims another user
    400 → { error: 'invalid_body' }
</interfaces>

      async function authenticate(req: Request, body: { mentioned_by_user_id?: string; commenter_user_id?: string }): Promise<AuthOutcome> {
        const bearer = bearerFromReq(req);
        if (!bearer) return { kind: 'reject', status: 401, code: 'unauthorized' };
        // Path A: service role
        const serviceRoleKey = Deno.env.get('SUPABASE_SERVICE_ROLE_KEY') ?? '';
        if (serviceRoleKey && constantTimeEqual(bearer, serviceRoleKey)) return { kind: 'service_role' };
        // Path B: user JWT
        const admin = getAdmin();
        const { data, error } = await admin.auth.getUser(bearer);
        if (error || !data?.user?.id) return { kind: 'reject', status: 401, code: 'unauthorized' };
        const claimedUserId = body.mentioned_by_user_id ?? body.commenter_user_id ?? '';
        if (!claimedUserId || claimedUserId !== data.user.id) return { kind: 'reject', status: 403, code: 'identity_mismatch' };
        return { kind: 'user', userId: data.user.id };
      }

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser (user JWT) → notify-community | Allowed when JWT.sub === body.mentioned_by_user_id (or commenter_user_id); rejects cross-user impersonation |
| Orchestrator / cron / DB-trigger → notify-community | Service-role bearer; full trust |
| notify-community → notification-send | Always service-role; notification-send is the rate-limit + dedup gate |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-44-06 | DoS (mention spam) | notify-community fan-out | mitigate | community_post_mentions PRIMARY KEY (post_id, user_id) dedupes per-post; notification_category_config.daily_cap=20 (from Plan 44-02). Self-mention skipped. |
| T-44-03b | Spoofing (auth gate) | notify-community auth | mitigate | constantTimeEqual against SUPABASE_SERVICE_ROLE_KEY for service path; admin.auth.getUser(bearer) for user JWT path with self-ID check against body. Deno test proves missing bearer = 401, mismatched user = 403. |
| T-44-01b | Information Disclosure (PII in logs) | notify-community console.log | mitigate | sha256 hash any user_id or email before logging. |
| T-44-08 | Elevation of Privilege (user pretends to be another user via body forgery) | notify-community user JWT path | mitigate | The Fn rejects with 403 identity_mismatch when JWT.sub != body.mentioned_by_user_id / commenter_user_id.
