**5. [correctness] Out-of-corpus relevance gate is applied to tier-boosted score, not raw cosine — lets irrelevant content past the refusal floor**
`supabase/functions/rag-retrieve/index.ts:236-237`  ·  _cluster: fn-ai-rag-content_

- **Problem:** The out-of-corpus gate is meant to refuse when max raw cosine similarity < OUT_OF_CORPUS_COSINE_FLOOR (0.65), as documented in refusal.ts ("refuse when max(cosine_similarity) < this threshold") and reflected by the response field named max_cosine. Result: genuinely off-topic / out-of-corpus content can be surfaced to GLP-1 patients as an answer instead of being refused, and the returned max_cosine value is mislabeled (it is a boosted score, not a cosine). The boost is exactly designed to exceed 1.0× so this is reachable for any Tier-A near-miss.
- **Proposed fix:** Gate on raw cosine, not the boosted score: `const maxCosine = reweighted.length > 0 ? Math.max(...reweighted.map((r) => r.raw_score)) : 0; if (shouldRefuseOutOfCorpus(maxCosine)) { const refusal = await outOfCorpusRefusal(traceId, maxCosine, body.filters?.topic_tag); ... }`.
